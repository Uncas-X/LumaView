Требуется macOS 13+; один пакет поддерживает Intel и Apple Silicon. Скачайте и распакуйте ZIP, затем перетащите `LumaView.app` в «Программы».

Нативный медиапросмотрщик для macOS, вдохновлённый быстрым просмотром в Picasa Photo Viewer: просмотр соседних файлов, масштабирование, перемещение, поворот, лента миниатюр, полный экран и слайд-шоу. В версии 1.5 появились обложки и реальные аудиоволны, навигация по многостраничным документам, векторный холст с перерисовкой при масштабировании и многоязычный интерфейс, по умолчанию следующий языку системы. Приложение использует собственное название и оригинальную иконку; полное совпадение с функциями и взаимодействиями исторической Picasa не заявляется.

В 1.7.2 унифицировано отображение прозрачности: прозрачные области PNG, GIF, PSD / PSB и других растровых изображений показывают текущий фон просмотрщика, а тень следует фактическому контуру и прозрачности изображения. Шахматный фон и прямоугольная тень всего прозрачного холста больше не отображаются. PDF и другие документы по-прежнему показываются на белом листе.

Сохранены оптимизации PSD / PSB версии 1.7.1: лента прежде всего читает корректный встроенный JPEG, а основной вид декодирует настоящий совместимый композит; RLE читается блоками. Также исправлено создание миниатюр небольших композитов с некоторыми ICC-профилями.

## Использование и установка

Требуется macOS 13 или новее; поддерживаются Intel и Apple Silicon.

1. Скачайте `LumaView-macOS.zip` из [Releases](https://github.com/Uncas-X/LumaView/releases), распакуйте, перенесите `LumaView.app` в папку «Программы» и откройте.
2. Перетащите изображение, видео, аудио или папку либо нажмите `⌘O`, чтобы выбрать файлы. При открытии одного файла показываются медиа из той же папки, при множественном выборе — выбранные файлы. Сканируется только текущий уровень папки, без вложенных папок.
3. В Finder можно нажать файл правой кнопкой и выбрать «Открыть в программе → LumaView».

Локальная сборка имеет временную подпись и не нотарифицирована Apple. Если Gatekeeper другого Mac блокирует скачанную копию, после проверки источника разрешите её открытие в системных настройках «Конфиденциальность и безопасность».

## Приложение по умолчанию

Выберите **LumaView → Приложение по умолчанию…**, нажмите `⌘,` или откройте настройки из меню «Ещё». Форматы сгруппированы по изображениям, векторам / документам, видео и аудио; найдите и отметьте нужные, затем нажмите «Назначить приложением по умолчанию для выбранных форматов». При каждом открытии диалога, повторной активации приложения и завершении настройки считываются реальные системные ассоциации: галочка означает, что вся группа открывается текущей копией LumaView; черта — что ассоциирована только часть типов или используется другая копия. Системные ассоциации сохраняются после перезапуска; ещё не применённые отметки не выдаются за успешно установленное состояние. Верхняя команда «Выбрать все форматы» охватывает изображения, векторные документы, видео и аудио независимо от поиска; внутри категории можно выбрать всё отдельно. Очистка снимает только текущий выбор и не отменяет существующие системные ассоциации.

При настройке отображается прогресс, а результат каждого изменения повторно считывается из системы. Отмена прекращает последующие изменения, сохраняя уже выполненные. Список форматов показывает доступные ассоциации файлов, а не гарантирует проверку каждого внутреннего кодека и файла; подробности см. в [описании форматов и предпросмотра](../i18n/ru/FORMATS.md).

## Просмотр и воспроизведение

При первом открытии окно разворачивается на доступную область текущего экрана; `F` включает полный экран. Нижняя лента позволяет переключать файлы; панель управления скрывается, если мышь некоторое время остаётся в области изображения, и появляется при движении мыши.

В 1.5.2 исправлены пустые и мигающие миниатюры при длительном просмотре больших папок: видимые миниатюры удерживаются отдельно, загрузка невидимых вовремя отменяется, а результаты из предыдущей папки не попадают в новый список. Для недекодируемых файлов отображается стабильная заглушка; при возвращении к этому диапазону возможна повторная попытка.

Изображения и видео поддерживают масштабирование, перемещение, поворот и полный экран. Окно, переключение изображений, масштабирование и поворот используют короткие плавные переходы, которые можно прерывать дальнейшими действиями. Системная настройка «Уменьшение движения» отключает эти переходы, но анимированные изображения продолжают воспроизводиться. По умолчанию фон полупрозрачный, с эффектом матового стекла; пробел переключает матовое стекло, тёмный и светлый фон.

Для прозрачных областей растровых изображений действует единое правило: виден текущий фон, тень следует только пикселям с содержимым, полупрозрачные края сохраняют свою прозрачность. При воспроизведении GIF / APNG тень обновляется с каждым кадром. При копировании сохраняются исходные прозрачные пиксели без фона и тени просмотрщика.

Элементы воспроизведения, остановки, позиции и громкости аудио/видео расположены над лентой. После открытия воспроизведение начинается автоматически; по окончании остаётся последний момент, `P` запускает повтор, `S` останавливает и возвращает в начало. Нижняя кнопка слайд-шоу независима от управления аудио/видео: после включения непрерывного воспроизведения через `⌘4` изображения сменяются с заданным интервалом, а аудио/видео — после окончания. Отдельное воспроизведение аудио/видео само по себе не переходит к следующему файлу.

В первую очередь используется нативное воспроизведение macOS. Если система не может воспроизвести файл напрямую, встроенные универсальные FFmpeg 9.0.2 и dav1d 1.5.3 локально подготавливают совместимый файл; когда возможно, сначала меняется контейнер, затем предпринимается перекодирование. Дополнительный проигрыватель, Homebrew или пакет кодеков не нужны, сеть не используется. Совместимое воспроизведение ожидает подготовки всего файла с отображением прогресса; переключение файла или закрытие окна отменяет подготовку. Первая подготовка длинного видео может потребовать значительного времени и дополнительного дискового пространства.

Через `C` или меню «Ещё» настраиваются циклический просмотр, поведение колеса, закрытие по фону, лента, сортировка и интервал слайд-шоу (2, 3, 5, 8, 10 секунд). Колесо по умолчанию масштабирует; удержание `Ctrl` временно переключает его на просмотр файлов. Если по умолчанию выбрано переключение файлов, `Ctrl` временно включает масштабирование. «Закрывать щелчком по фону вне изображения» включено по умолчанию. Настройки сохраняются локально.

## Контекстное меню и копирование

Щёлкните основной вид правой кнопкой (или с Ctrl), чтобы выбрать «Открыть в программе → Приложение / Другое приложение…» или «Показать в Finder». Выбор программы действует только для этого открытия и не меняет ассоциацию по умолчанию; оба действия доступны и для недекодируемых файлов.

- Изображения: «Копировать изображение» сохраняет поворот текущего вида и прозрачные пиксели, копируя целое декодированное изображение, а не панель инструментов или масштабированный участок экрана.
- Видео: «Копировать текущий кадр» копирует кадр, соответствующий моменту открытия контекстного меню, сохраняет ориентацию видео и поворот вида, не меняет позицию и состояние воспроизведения.
- PDF / AI с PDF-совместимостью: щёлкните растровое изображение на странице, чтобы выбрать «Копировать это изображение», либо «Копировать текущую страницу». Позиция учитывается корректно после масштабирования, перемещения и поворота. Обычный текст и векторные области не считаются изображениями; при сложных масках и цветовых пространствах копируется видимый результат области изображения, возможно с наложенным текстом. Страница, отсканированная одной картинкой, копируется как целое сканированное изображение.
- `⌘C` копирует текущее изображение, кадр видео или страницу документа; для аудио копирование изображения недоступно. В буфер помещаются PNG и TIFF; после переключения файла / страницы или закрытия устаревший результат копирования не перезапишет буфер.

При копировании документов и встроенных изображений создаётся растр с длинной стороной до 8192 пикселей и примерно 32 миллионами пикселей; векторные команды PDF/SVG в буфер не помещаются. Если большая картинка отображается как ограниченный предпросмотр, копируется этот предпросмотр. Поиск изображений в PDF ограничен по сложности; изображения в узорных заливках и другие особые структуры могут не выделяться отдельно, но текущую страницу скопировать можно.

Стандартные заголовки SVG 1.0/1.1 разбираются офлайн, без внешних DTD. В 1.7 встроен Ghostscript 10.08.0: EPS / PostScript и старые PostScript AI преобразуются в PDF с сохранением путей, текста и встроенных изображений, затем основной вид перерисовывает вектор при масштабировании. Многостраничные PS используют существующую навигацию по страницам. Дополнительное ПО не требуется. При неудачном преобразовании EPS с корректным встроенным TIFF возможен резервный предпросмотр с явной пометкой TIFF. Растровые изображения исходного файла не превращаются в векторные.

## Аудио, документы и языки

Если в аудио есть встроенная обложка, основной вид показывает её; иначе асинхронно анализируются реальные отсчёты и строится волна всего аудиофайла. Во время анализа отображается заглушка, воспроизведение не ждёт готовности волны. В правом нижнем углу миниатюр аудио и видео одинаково отображается `▶ Длительность` с общими шрифтом, фоном и положением; до чтения длительности показывается `▶ –:––`. Обложка берётся только из встроенных метаданных, а не из сети или соседних файлов.

PDF, AI с PDF-совместимостью и многостраничный TIFF поддерживают просмотр страниц. Меньшие миниатюры страниц, ползунок и текущая / общая страницы расположены над лентой файлов. `↑` переводит фокус на страницы, `↓` — на файлы; оранжевая рамка выбранной миниатюры показывает активный ряд, серая сохраняет выбор в другом ряду. Дополнительных меток «Страницы / Файлы» нет. `←` / `→`, `J` / `K` и `Home` / `End` действуют на текущий фокус. Щелчок по ряду также переводит на него фокус. В начале и конце документа навигация останавливается, не переходя случайно к другому файлу. Нижние кнопки предыдущего / следующего файла всегда переключают файлы. Навигация по страницам остаётся доступной при скрытой ленте файлов.

PDF, SVG и AI с PDF-совместимостью рисуют видимую область исходными векторными командами при текущем масштабе, а не увеличивают фиксированное превью. Прозрачные области документа отображаются как белая бумага без шахматной сетки. При переключении страниц сначала готовится целая новая страница, затем выполняется плавное проявление всей страницы; фоновая отрисовка векторных деталей не оставляет пустых плиток, появляющихся поочерёдно. Встроенные фотографии и другие растровые элементы ограничены своим исходным разрешением.

Выберите **LumaView → Язык…** или откройте настройку из меню «Ещё». По умолчанию используется язык системы; поддерживаются упрощённый и традиционный китайский, английский, японский, корейский, французский, немецкий, испанский, итальянский, португальский, русский, арабский, хинди, турецкий, нидерландский и польский. Меню приложения, подсказки, страницы и настройки обновляются сразу, выбранный язык сохраняется локально. Для неподдерживаемого системного языка используется английский; редкие ошибки декодирования также могут отображаться на английском. Имена файлов, пути и текст внутри файлов не меняются.

## Поддержка и ограничения

- Изображения декодируются системным ImageIO; фактическая поддержка JPEG, PNG, GIF, HEIC, TIFF, BMP, WebP, RAW и других форматов зависит от версии системы и содержимого файла.
- Огромные изображения больше не отклоняются только из-за превышения 150 миллионов пикселей. При необходимости создаётся уменьшенный предпросмотр для ограничения памяти с сохранением исходных размеров и ориентации. Масштаб 100% рассчитывается по исходным размерам, но не восстанавливает недекодированные детали.
- Поддерживается векторное отображение SVG, PDF, AI с PDF-совместимостью, а также EPS / PS / старых AI через встроенный интерпретатор. Многостраничные PDF / AI / PS листаются; SVG запрещает скрипты и внешние ресурсы. Растр внутри вектора ограничен исходным разрешением; отсутствующие невстроенные шрифты могут заменяться.
- PostScript выполняется в отдельном процессе с SAFER и системной песочницей: разрешены только текущие временные входной и выходной файлы, сеть запрещена. При быстром переключении можно отменить процесс; миниатюры и основной вид используют общий кеш завершённых результатов. Одна интерпретация ограничена 90 секундами, вывод — 1 GB, целевой размер очищаемого кеша — 2 GB.
- Photoshop PSD / PSB показывает сохранённый композит, без редактирования слоёв. Для огромного холста создаётся предпросмотр в рамках бюджета памяти с сохранением исходных размеров; цветовые режимы, глубина и сжатие описаны в FORMATS.md.
- Встроенное совместимое декодирование расширяет поддержку аудио и видео, но DRM, повреждённые файлы и проприетарные кодеки без доступного декодера могут не воспроизводиться. Расширение не гарантирует поддержку кодирования; все форматы, устройства и версии ОС по отдельности не проверены.
- Кеш совместимости очищается до целевого размера 2 GB; используемые файлы могут временно превысить этот размер. Один подготовленный файл ограничен 8 GB, свободный остаток диска должен быть не меньше 512 MB. При нехватке места подготовка прекращается с сообщением.
- TIFF поддерживает страницы; другие составные форматы без реализованной пагинации показывают первый кадр. Поворот вида не записывается в исходный файл. Нет редактирования, удаления, базы медиатеки, обмена, облачной синхронизации или управления внешними субтитрами.
- Читаются только открытые пользователем локальные медиа и их папка; совместимое воспроизведение пишет в локальный кеш, не загружает медиа на сервер и не меняет оригиналы.

Дополнительные примеры форматов и ограничения кеша/предпросмотра см. в [FORMATS.md](../i18n/ru/FORMATS.md).

## Сборка из исходников

Нужны Xcode или Command Line Tools с компилятором Swift. Репозиторий и исходный пакет уже содержат универсальные медиаинструменты Intel / Apple Silicon; обычная сборка не требует установки или скачивания сторонних зависимостей. После клонирования или скачивания перейдите в корень репозитория с `build.sh`; исходная структура рабочего каталога разработчика не нужна.

```bash
cd /path/to/LumaView
./build.sh
open ../LumaView.app
```

По умолчанию создаётся универсальное приложение; `./build.sh --host` собирает только архитектуру текущего Mac. Приложение создаётся рядом с каталогом исходников как `LumaView.app`; другой путь задаётся через `LUMAVIEW_APP_PATH`. Рабочая папка сборки и тестов по умолчанию — `.build/` внутри репозитория, переопределяемая через `LUMAVIEW_WORK_ROOT`; сгенерированные файлы исключены в `.gitignore`.

Тестовая сборка `LUMAVIEW_TEST_BUILD=1 ./build.sh --host` создаёт отдельное приложение `LumaView Tests`, не регистрирующее открытие файлов, чтобы тестовая копия не перехватывала ассоциации установленной версии. Скрипты UI-тестов по умолчанию используют этот режим; уже собранное приложение можно указать через `LUMAVIEW_SKIP_TEST_BUILD=1` и `LUMAVIEW_TEST_APP_PATH`.

FFmpeg собран по LGPL 2.1 или новее, статически связанный dav1d использует BSD 2-Clause. Соответствующие архивы исходников, контрольные суммы и лицензии включены в исходный пакет. Для пересборки медиаинструментов требуются Xcode Command Line Tools, Python 3, Meson 1.12.1 и Ninja 1.13.2; их можно установить в виртуальное окружение Python, затем выполнить `./tools/build-media-tools.sh`. Шаги и конфигурация приведены в [ThirdParty/README.md](../i18n/ru/ThirdParty/README.md). PostScript использует отдельный Ghostscript 10.08.0 (AGPL-3.0-or-later), поставляемый с лицензией, полным соответствующим исходным кодом и скриптом сборки; обычная сборка приложения использует готовые компоненты двух архитектур, пересборка описана в [документации Ghostscript](../i18n/ru/ThirdParty/README-Ghostscript.md).

## Исходники и проверка

- `Sources/`: интерфейс AppKit, медиахолст, загрузка растров/векторов, жизненный цикл аудио/видео, подготовка совместимости и настройки приложения по умолчанию.
- `Resources/Localizations/`: переводы интерфейса и перечень основных ключей.
- `Resources/MediaFormats.json`: каталог форматов; `Resources/MediaTools/`: встроенные FFmpeg / ffprobe.
- `ThirdParty/sources/`, `Resources/ThirdPartyNotices/`: соответствующие исходники и лицензии медиаинструментов.
- `build.sh`: компиляция, упаковка и локальная подпись универсального приложения; `tools/build-media-tools.sh`: пересборка медиаинструментов.

./Tests/run-core-tests.sh

Модульным тестам аудиодекодирования для создания MP3 / FLAC / Opus нужен разработческий FFmpeg с соответствующими энкодерами; путь задаётся через `LUMAVIEW_TEST_FFMPEG`. Само приложение и UI-тесты аудио используют только поставляемые компоненты.

Интеграционные проверки интерфейса требуют входа в графический сеанс macOS: они открывают приложение и проверяют взаимодействие на автоматически созданных медиа. Сборки и сохранённые отчёты по умолчанию находятся в `.build/`, часть временных материалов — в системной временной папке. Тесты по умолчанию не читают личные фотографии. Тесты копирования через контекстное меню используют отдельный именованный буфер и не заменяют текущий буфер пользователя; проверки открытия в другом приложении / Finder / ассоциаций используют имитации и не меняют файловые ассоциации. Проверки поставленного выпуска см. в [TEST-RESULTS.txt](../i18n/ru/TEST-RESULTS.md).

Сохранённые отчёты в `Tests/` — исторические записи соответствующих версий, а не свидетельство автоматического прохождения тестов в текущем окружении после клонирования. Личные имена образцов анонимизированы, оригинальные медиа в репозиторий не включены. Пути `work/` в исторических отчётах показывают источник тогдашнего тестирования и не требуются для текущей сборки. Репозиторий хранит соответствующие исходные архивы, контрольные суммы и лицензии сторонних инструментов, поэтому первое клонирование довольно объёмно.
