支援 macOS 13+，同一個安裝包兼容 Intel 與 Apple Silicon。下載 ZIP 後解壓，將 `LumaView.app` 拖入“應用程式”即可安裝。

一款 macOS 原生媒體查看器，以 Picasa Photo Viewer 的快捷看圖習慣為參考，支援同資料夾瀏覽、縮放、拖動、旋轉、膠片帶、全屏和幻燈片。1.5 加入音訊封面與真實波形、多頁文檔導航、隨縮放繪制的矢量畫布，以及預設跟隨系統的多語言設定。採用獨立名稱與原創圖標，不宣稱與歷史版 Picasa 的全部功能和交互完全一致。

1.7.2 統一圖片透明區域的顯示：PNG、GIF、PSD / PSB 等柵格圖片直接露出當前查看背景，陰影隨實際圖像輪廓和透明度變化，不再顯示灰白格或整張透明畫布的矩形陰影。PDF 等文檔仍按白色紙面顯示。

1.7.1 的 PSD / PSB 預覽優化繼續保留：膠片帶優先讀取有效的內嵌 JPEG，主圖仍解碼真正的兼容合成圖；RLE 使用分塊讀取，並修復部分帶 ICC 配置的小尺寸合成圖無法生成縮略圖的問題。

## 使用與安裝

需要 macOS 13 或更新系統，支援 Intel 與 Apple Silicon。

1. 從 [Releases](https://github.com/Uncas-X/LumaView/releases) 下載 `LumaView-macOS.zip`，解壓後將 `LumaView.app` 拖入“應用程式”資料夾並打開。
2. 拖入圖片、影片、音訊或資料夾，也可以按 `⌘O` 選擇檔案。單獨打開一個檔案時會列出同資料夾的媒體，多選時瀏覽所選檔案。資料夾只掃描當前層，不遞歸掃描子資料夾。
3. 在 Finder 中也可以右鍵檔案，選擇“打開方式 → LumaView”。

本地構建使用臨時簽名，未進行 Apple 公證。如果其他 Mac 的 Gatekeeper 攔截下載的副本，可在確認來源後使用系統“隱私與安全性”中的允許打開選項。

## 預設打開方式

選擇 **LumaView → 預設打開方式…**，按 `⌘,`，或從“更多”選單打開設定。格式按圖片、矢量 / 文檔、影片、音訊分組，可搜索並勾選，再點擊“設為所選格式的預設應用”。彈窗每次打開、應用重新激活及設定完成後，讀取系統實際關聯：勾選表示該組已全部由當前 LumaView 打開，橫線表示部分類型已關聯或仍指向另一個副本。系統關聯跨重啓保留；尚未應用的臨時勾選不會冒充已成功設定。頂部“全選所有格式”覆蓋所有圖片、矢量文檔、影片和音訊，不受搜索條件影響；分類內仍可單獨全選。清空僅清除本次選擇，不取消已經存在的系統預設關聯。

設定會顯示進度，並逐項回讀系統結果。取消會停止後續設定，已經完成的更改仍會保留。格式列表表示可選擇的檔案關聯，不代表每種內部編碼或每個檔案都經過實測；具體範圍見 [格式與預覽說明](../i18n/zh-Hant/FORMATS.md)。

## 查看與播放

首次打開檔案會展開到當前屏幕可用區域，按 `F` 進入全屏。底部膠片帶可直接切換檔案；操作欄在滑鼠停留於畫面區域一段時間後隱藏，移動滑鼠即可顯示。

1.5.2 修復連續瀏覽大資料夾時縮略圖空白或反復閃爍的問題：當前可見縮略圖獨立保留，離屏加載及時取消；更換資料夾後舊結果不會寫入新列表。無法解碼的檔案顯示穩定佔位圖，重新進入該範圍時可再次嘗試。

圖片和影片都可以縮放、拖動、旋轉和全屏。窗口、切圖、縮放與旋轉採用短暫平滑過渡，連續操作可以打斷過渡。開啓系統“減少動態效果”後會停用這些自定義過渡，動圖仍正常播放。預設使用半透明毛玻璃背景；按空格切換毛玻璃、深色和淺色。

柵格圖片的透明區域使用統一規則：顯示當前背景，陰影只跟隨有內容的像素，半透明邊緣保留其透明度；GIF / APNG 播放時陰影隨每幀變化。複製圖片仍保留原圖透明像素，不包含查看器背景或陰影。

音影片的播放、停止、進度和音量控件位於膠片帶上方。打開後自動播放，播放結束停留在結尾，按 `P` 可以重播；`S` 停止並回到開頭。下方的幻燈片按鈕與音影片播放按鈕獨立：`⌘4` 開啓連續播放後，圖片按設定間隔切換，音影片等待播放完畢再切換。單獨播放音影片不會自動跳到下一項。

優先使用 macOS 原生播放。系統無法直接播放時，應用使用內置的通用版 FFmpeg 9.0.2 和 dav1d 1.5.3，在本機準備兼容檔案；符合條件時先嘗試更換容器，再嘗試轉碼。無需另裝播放器、Homebrew 或解碼包，也不訪問網路。兼容播放需等待整個檔案準備完成，期間顯示進度；切換檔案或關閉窗口可取消準備。長影片的首次準備可能需要較長時間和額外磁碟空間。

`C` 或“更多”選單可設定循環瀏覽、滾輪行為、背景關閉、膠片帶、排序及幻燈片間隔（2、3、5、8、10 秒）。滾輪預設縮放，按住 `Ctrl` 臨時切換為瀏覽檔案；如果將滾輪預設設為瀏覽，`Ctrl` 則臨時縮放。“點擊畫面外背景關閉”預設開啓。這些偏好保存在本機。

## 右鍵選單與複製

在主畫面右鍵單擊（或 Ctrl 單擊），可選擇“打開方式 → 應用 / 其他應用…”或“在 Finder 中顯示”。打開方式只針對這次打開，不改動預設關聯；無法解碼的檔案也可以用這兩個選項處理。

- 圖片：選擇“複製圖片”。保留當前視圖的旋轉方向與透明像素，複製整張當前解碼圖，不截取工具欄或縮放後的屏幕區域。
- 影片：選擇“複製當前幀”。複製打開右鍵選單時的對應影片幀，保留影片方向及視圖旋轉，不改變播放位置和播放狀態。
- PDF / PDF 兼容 AI：在頁面中的位圖上右鍵可“複製此圖片”，也可“複製當前頁”。縮放、拖動及旋轉後仍按實際點擊位置識別。普通文字和矢量區域不當作圖片；複雜蒙版或色彩空間會複製該圖片區域的可見效果，可能包含該區域的疊加文字。掃描為一張圖片的頁面會按整張掃描圖複製。
- `⌘C` 複製當前圖片、當前影片幀或當前文檔頁；音訊不提供圖片複製。剪貼簿提供 PNG 和 TIFF，切換檔案 / 頁面或關閉後，舊複製結果不會覆蓋剪貼簿。

複製文檔和內嵌圖片生成最長邊至多 8192 像素、約 3200 萬像素的位圖，不會把 PDF/SVG 矢量指令寫入剪貼簿。大圖片若正在顯示有界預覽，複製的是該預覽。PDF 圖片掃描有複雜度限制；圖案填充中的圖片等特殊結構可能不能單獨選取，仍可複製當前頁。

標準 SVG 1.0/1.1 檔案頭可離線解析，不加載外部 DTD。1.7 內置 Ghostscript 10.08.0，將 EPS / PostScript 和舊版 PostScript AI 轉為保留路徑、文本及嵌入圖片的 PDF，主畫面隨縮放重新繪制矢量；多頁 PS 沿用現有內頁導航。無需安裝額外軟體。轉換失敗但存在有效內嵌 TIFF 的 EPS 仍可回退預覽，並明確標為 TIFF。原檔案中的位圖不會變成矢量。

## 音訊、文檔與語言

音訊有內嵌封面時，主畫面優先顯示封面；沒有可用封面時，異步分析實際採樣並顯示整段音訊的波形。分析期間先顯示佔位圖，播放無需等待波形完成。音訊和影片的膠片帶右下角統一顯示 `▶ 時長`，使用相同的字體、底色和位置；尚未讀出時顯示 `▶ –:––`。封面來自檔案內嵌元資料，不從網路或同目錄搜索圖片。

PDF、PDF 兼容 AI 和多頁 TIFF 支援內頁瀏覽。較小的內頁縮略圖、頁碼進度條及當前頁 / 總頁數位於檔案膠片帶上方。按 `↑` 聚焦內頁，按 `↓` 聚焦檔案；當前層選中縮略圖的橙色邊框標出焦點，另一層以灰色邊框保留選中狀態；不額外顯示“內頁 / 檔案”標籤。`←` / `→`、`J` / `K` 和 `Home` / `End` 操作當前焦點。點擊某一層也會聚焦該層。內頁到達首尾會停住，不會意外跳到其他檔案。下方上一 / 下一檔案按鈕始終切換檔案。隱藏檔案膠片帶時，內頁導航仍保留。

PDF、SVG 以及 PDF 兼容 AI 使用原始矢量指令按當前縮放繪制可見區域，不再放大固定預覽圖。透明文檔區域顯示純白紙面，沒有棋盤格。切換內頁時，完整新頁準備好後再做整頁淡入過渡，後台矢量細節繪制不會留下逐塊出現的空白。檔案內部嵌入的照片等位圖仍受其原始分辨率限制。

選擇 **LumaView → 語言…**，也可從“更多”選單打開。預設跟隨系統，支援簡體中文、繁體中文、英語、日語、韓語、法語、德語、西班牙語、意大利語、葡萄牙語、俄語、阿拉伯語、印地語、土耳其語、荷蘭語和波蘭語。應用選單、工具提示、分頁和設定介面即時更新，所選語言保存在本機。不支援的系統語言回退到英語；少見解碼錯誤也可能以英語顯示。檔案名、路徑和檔案內原有文字保持原樣。

## 支援範圍與限制

- 圖片通過系統 ImageIO 解碼，JPEG、PNG、GIF、HEIC、TIFF、BMP、WebP、RAW 等的實際支援取決於系統版本和檔案內容。
- 超大圖片不再因超過 1.5 億像素而直接拒絕。為限制記憶體，必要時下採樣預覽，同時保留原始尺寸和方向資訊；100% 縮放仍按原始尺寸計算，但不能恢復預覽中未解碼的像素細節。
- 支援 SVG、PDF、PDF 兼容 AI，以及內置解釋器處理的 EPS / PS / 舊版 AI 的矢量顯示。多頁 PDF / AI / PS 可翻頁；SVG 拒絕腳本與外部資源。矢量中的位圖仍受源分辨率限制，缺失的未嵌入字體可能替換。
- PostScript 在獨立進程中開啓 SAFER 並使用系統沙箱：只允許當前暫存輸入與輸出，禁止網路；快速切檔案可取消，縮略圖和主圖共享完成快取。單次解釋限時 90 秒，輸出最多 1 GB，快取清理目標為 2 GB。
- Photoshop PSD / PSB 顯示保存時的合成圖；不提供圖層編輯。超大畫布按記憶體預算生成預覽並保留原始尺寸，具體色彩模式、位元深度和壓縮支援見 FORMATS.md。
- 內置兼容解碼擴大了音影片範圍，但 DRM、損壞檔案、缺少可用解碼器的專有編碼仍可能無法播放。格式副檔名不保證內部編碼可解碼，未對所有格式、設備和系統版本逐項實測。
- 兼容快取以 2 GB 為清理目標，當前使用的檔案可能使快取暫時超過該目標；單個準備檔案最多 8 GB，並保留至少 512 MB 磁碟餘量。空間不足時會停止準備並提示。
- TIFF 支援多頁瀏覽，其他未實現分頁的復合圖片格式仍顯示首幅；查看旋轉不寫回原檔案。不提供編輯、刪除、圖庫資料庫、分享或雲同步，也不提供外掛字幕管理。
- 只讀取使用者打開的本地媒體和所在資料夾；兼容播放寫入本機快取，不上傳媒體，不修改原始檔案。

更多格式示例、快取與預覽邊界見 [FORMATS.md](../i18n/zh-Hant/FORMATS.md)。

## 從原始碼構建

需要 Xcode 或包含 Swift 編譯器的 Command Line Tools。倉庫與原始碼包已附帶 Intel / Apple Silicon 通用版媒體工具，正常構建無需另外安裝或下載第三方依賴。克隆或下載後，進入含有 `build.sh` 的倉庫根目錄即可構建，不需要原開發工作區的目錄結構。

```bash
cd /path/to/LumaView
./build.sh
open ../LumaView.app
```

預設生成通用應用，`./build.sh --host` 只構建當前 Mac 架構。應用預設位於原始碼目錄旁的 `LumaView.app`，可以通過 `LUMAVIEW_APP_PATH` 指定其他位置。構建和測試工作目錄預設是倉庫內的 `.build/`，可通過 `LUMAVIEW_WORK_ROOT` 覆蓋；這些生成檔案已由 `.gitignore` 排除。

測試構建使用 `LUMAVIEW_TEST_BUILD=1 ./build.sh --host`：生成獨立的 `LumaView Tests` 應用，不聲明檔案打開方式，避免測試副本搶佔正式安裝版。介面測試腳本預設使用該模式；可以用 `LUMAVIEW_SKIP_TEST_BUILD=1` 和 `LUMAVIEW_TEST_APP_PATH` 指定已構建的應用。

FFmpeg 按 LGPL 2.1 或更新版本構建，靜態鏈接的 dav1d 使用 BSD 2-Clause 許可證。對應原始碼歸檔、校驗值和許可證隨原始碼包提供。若要重建媒體工具，需要 Xcode Command Line Tools、Python 3、Meson 1.12.1 和 Ninja 1.13.2；可在 Python 虛擬環境中安裝後運行 `./tools/build-media-tools.sh`。具體步驟和構建配置見 [ThirdParty/README.md](../i18n/zh-Hant/ThirdParty/README.md)。PostScript 使用獨立的 Ghostscript 10.08.0（AGPL-3.0-or-later），隨包附帶許可證、完整對應原始碼和構建腳本；正常應用構建使用已附帶的雙架構元件，重建方法見 [Ghostscript 說明](../i18n/zh-Hant/ThirdParty/README-Ghostscript.md)。
