Приложение запускается с настройкой **Как в системе**. Выбирается первый поддерживаемый язык из предпочтительного списка macOS, а если подходящих нет — английский. Язык, выбранный в **LumaView → Язык…**, применяется сразу и запоминается только для этого приложения.

Поддерживаются упрощённый китайский, традиционный китайский, английский, японский, корейский, французский, немецкий, испанский, итальянский, португальский, русский, арабский, хинди, турецкий, нидерландский и польский. Варианты португальского сейчас используют бразильский каталог. Названия языков в списке намеренно даны на самих языках, чтобы можно было выйти из незнакомого интерфейса.

`catalog.json` связывает читаемые исходные ключи на упрощённом китайском с переводами. `core-keys.json` определяет общие элементы управления, меню, настройки, навигацию документов, метаданные и клавиатурную справку, обязательные для каждого каталога. Редкие диагностические сообщения используют английский резервный текст при отсутствии перевода. Имена файлов, каталогов, кодеков, форматов и встроенные метаданные камеры не меняются. Системные диалоги переводит сама ОС на свой язык.

Для статического текста используйте `L10n.tr("source key")`. Для динамического — `L10n.format("第 %d / %d 页", current, total)`, а не интерполяцию китайской строки до перевода. Типы и количество подстановок должны совпадать во всех переводах. Наблюдайте за `L10n.languageDidChange`, чтобы обновлять существующий интерфейс и перерисовывать текст. Тесты используют `useLanguageForTesting`, не меняя сохранённый язык пользователя.

Запустите `Tests/run-localization-tests.sh` для проверки выбора локали, покрытия основных ключей, совпадения подстановок, резервного языка и направления арабского текста. Профессиональная лингвистическая редактура переводов не проводилась.
