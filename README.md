# LumaView 1.7.2

一款 macOS 原生媒体查看器，以 Picasa Photo Viewer 的快捷看图习惯为参考，支持同文件夹浏览、缩放、拖动、旋转、胶片带、全屏和幻灯片。1.5 加入音频封面与真实波形、多页文档导航、随缩放绘制的矢量画布，以及默认跟随系统的多语言设置。采用独立名称与原创图标，不宣称与历史版 Picasa 的全部功能和交互完全一致。

1.7.2 统一图片透明区域的显示：PNG、GIF、PSD / PSB 等栅格图片直接露出当前查看背景，阴影随实际图像轮廓和透明度变化，不再显示灰白格或整张透明画布的矩形阴影。PDF 等文档仍按白色纸面显示。

1.7.1 的 PSD / PSB 预览优化继续保留：胶片带优先读取有效的内嵌 JPEG，主图仍解码真正的兼容合成图；RLE 使用分块读取，并修复部分带 ICC 配置的小尺寸合成图无法生成缩略图的问题。

## 使用与安装

需要 macOS 13 或更新系统，支持 Intel 与 Apple Silicon。

1. 打开交付的 `LumaView.app`，或将它拖入“应用程序”文件夹后打开。
2. 拖入图片、视频、音频或文件夹，也可以按 `⌘O` 选择文件。单独打开一个文件时会列出同文件夹的媒体，多选时浏览所选文件。文件夹只扫描当前层，不递归扫描子文件夹。
3. 在 Finder 中也可以右键文件，选择“打开方式 → LumaView”。

本地构建使用临时签名，未进行 Apple 公证。如果其他 Mac 的 Gatekeeper 拦截下载的副本，可在确认来源后使用系统“隐私与安全性”中的允许打开选项。

## 默认打开方式

选择 **LumaView → 默认打开方式…**，按 `⌘,`，或从“更多”菜单打开设置。格式按图片、矢量 / 文档、视频、音频分组，可搜索并勾选，再点击“设为所选格式的默认应用”。弹窗每次打开、应用重新激活及设置完成后，读取系统实际关联：勾选表示该组已全部由当前 LumaView 打开，横线表示部分类型已关联或仍指向另一个副本。系统关联跨重启保留；尚未应用的临时勾选不会冒充已成功设置。顶部“全选所有格式”覆盖所有图片、矢量文档、视频和音频，不受搜索条件影响；分类内仍可单独全选。清空仅清除本次选择，不取消已经存在的系统默认关联。

设置会显示进度，并逐项回读系统结果。取消会停止后续设置，已经完成的更改仍会保留。格式列表表示可选择的文件关联，不代表每种内部编码或每个文件都经过实测；具体范围见 [格式与预览说明](FORMATS.md)。

## 查看与播放

首次打开文件会展开到当前屏幕可用区域，按 `F` 进入全屏。底部胶片带可直接切换文件；操作栏在鼠标停留于画面区域一段时间后隐藏，移动鼠标即可显示。

1.5.2 修复连续浏览大文件夹时缩略图空白或反复闪烁的问题：当前可见缩略图独立保留，离屏加载及时取消；更换文件夹后旧结果不会写入新列表。无法解码的文件显示稳定占位图，重新进入该范围时可再次尝试。

图片和视频都可以缩放、拖动、旋转和全屏。窗口、切图、缩放与旋转采用短暂平滑过渡，连续操作可以打断过渡。开启系统“减少动态效果”后会停用这些自定义过渡，动图仍正常播放。默认使用半透明毛玻璃背景；按空格切换毛玻璃、深色和浅色。

栅格图片的透明区域使用统一规则：显示当前背景，阴影只跟随有内容的像素，半透明边缘保留其透明度；GIF / APNG 播放时阴影随每帧变化。复制图片仍保留原图透明像素，不包含查看器背景或阴影。

音视频的播放、停止、进度和音量控件位于胶片带上方。打开后自动播放，播放结束停留在结尾，按 `P` 可以重播；`S` 停止并回到开头。下方的幻灯片按钮与音视频播放按钮独立：`⌘4` 开启连续播放后，图片按设定间隔切换，音视频等待播放完毕再切换。单独播放音视频不会自动跳到下一项。

优先使用 macOS 原生播放。系统无法直接播放时，应用使用内置的通用版 FFmpeg 9.0.2 和 dav1d 1.5.3，在本机准备兼容文件；符合条件时先尝试更换容器，再尝试转码。无需另装播放器、Homebrew 或解码包，也不访问网络。兼容播放需等待整个文件准备完成，期间显示进度；切换文件或关闭窗口可取消准备。长视频的首次准备可能需要较长时间和额外磁盘空间。

`C` 或“更多”菜单可设置循环浏览、滚轮行为、背景关闭、胶片带、排序及幻灯片间隔（2、3、5、8、10 秒）。滚轮默认缩放，按住 `Ctrl` 临时切换为浏览文件；如果将滚轮默认设为浏览，`Ctrl` 则临时缩放。“点击画面外背景关闭”默认开启。这些偏好保存在本机。

## 右键菜单与复制

在主画面右键单击（或 Ctrl 单击），可选择“打开方式 → 应用 / 其他应用…”或“在 Finder 中显示”。打开方式只针对这次打开，不改动默认关联；无法解码的文件也可以用这两个选项处理。

- 图片：选择“复制图片”。保留当前视图的旋转方向与透明像素，复制整张当前解码图，不截取工具栏或缩放后的屏幕区域。
- 视频：选择“复制当前帧”。复制打开右键菜单时的对应视频帧，保留视频方向及视图旋转，不改变播放位置和播放状态。
- PDF / PDF 兼容 AI：在页面中的位图上右键可“复制此图片”，也可“复制当前页”。缩放、拖动及旋转后仍按实际点击位置识别。普通文字和矢量区域不当作图片；复杂蒙版或颜色空间会复制该图片区域的可见效果，可能包含该区域的叠加文字。扫描为一张图片的页面会按整张扫描图复制。
- `⌘C` 复制当前图片、当前视频帧或当前文档页；音频不提供图片复制。剪贴板提供 PNG 和 TIFF，切换文件 / 页面或关闭后，旧复制结果不会覆盖剪贴板。

复制文档和内嵌图片生成最长边至多 8192 像素、约 3200 万像素的位图，不会把 PDF/SVG 矢量指令写入剪贴板。大图片若正在显示有界预览，复制的是该预览。PDF 图片扫描有复杂度限制；图案填充中的图片等特殊结构可能不能单独选取，仍可复制当前页。

标准 SVG 1.0/1.1 文件头可离线解析，不加载外部 DTD。1.7 内置 Ghostscript 10.08.0，将 EPS / PostScript 和旧版 PostScript AI 转为保留路径、文本及嵌入图片的 PDF，主画面随缩放重新绘制矢量；多页 PS 沿用现有内页导航。无需安装额外软件。转换失败但存在有效内嵌 TIFF 的 EPS 仍可回退预览，并明确标为 TIFF。原文件中的位图不会变成矢量。

## 音频、文档与语言

音频有内嵌封面时，主画面优先显示封面；没有可用封面时，异步分析实际采样并显示整段音频的波形。分析期间先显示占位图，播放无需等待波形完成。音频和视频的胶片带右下角统一显示 `▶ 时长`，使用相同的字体、底色和位置；尚未读出时显示 `▶ –:––`。封面来自文件内嵌元数据，不从网络或同目录搜索图片。

PDF、PDF 兼容 AI 和多页 TIFF 支持内页浏览。较小的内页缩略图、页码进度条及当前页 / 总页数位于文件胶片带上方。按 `↑` 聚焦内页，按 `↓` 聚焦文件；当前层选中缩略图的橙色边框标出焦点，另一层以灰色边框保留选中状态；不额外显示“内页 / 文件”标签。`←` / `→`、`J` / `K` 和 `Home` / `End` 操作当前焦点。点击某一层也会聚焦该层。内页到达首尾会停住，不会意外跳到其他文件。下方上一 / 下一文件按钮始终切换文件。隐藏文件胶片带时，内页导航仍保留。

PDF、SVG 以及 PDF 兼容 AI 使用原始矢量指令按当前缩放绘制可见区域，不再放大固定预览图。透明文档区域显示纯白纸面，没有棋盘格。切换内页时，完整新页准备好后再做整页淡入过渡，后台矢量细节绘制不会留下逐块出现的空白。文件内部嵌入的照片等位图仍受其原始分辨率限制。

选择 **LumaView → 语言…**，也可从“更多”菜单打开。默认跟随系统，支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、意大利语、葡萄牙语、俄语、阿拉伯语、印地语、土耳其语、荷兰语和波兰语。应用菜单、工具提示、分页和设置界面即时更新，所选语言保存在本机。不支持的系统语言回退到英语；少见解码错误也可能以英语显示。文件名、路径和文件内原有文字保持原样。

## 支持范围与限制

- 图片通过系统 ImageIO 解码，JPEG、PNG、GIF、HEIC、TIFF、BMP、WebP、RAW 等的实际支持取决于系统版本和文件内容。
- 超大图片不再因超过 1.5 亿像素而直接拒绝。为限制内存，必要时下采样预览，同时保留原始尺寸和方向信息；100% 缩放仍按原始尺寸计算，但不能恢复预览中未解码的像素细节。
- 支持 SVG、PDF、PDF 兼容 AI，以及内置解释器处理的 EPS / PS / 旧版 AI 的矢量显示。多页 PDF / AI / PS 可翻页；SVG 拒绝脚本与外部资源。矢量中的位图仍受源分辨率限制，缺失的未嵌入字体可能替换。
- PostScript 在独立进程中开启 SAFER 并使用系统沙箱：只允许当前暂存输入与输出，禁止网络；快速切文件可取消，缩略图和主图共享完成缓存。单次解释限时 90 秒，输出最多 1 GB，缓存清理目标为 2 GB。
- Photoshop PSD / PSB 显示保存时的合成图；不提供图层编辑。超大画布按内存预算生成预览并保留原始尺寸，具体颜色模式、位深和压缩支持见 FORMATS.md。
- 内置兼容解码扩大了音视频范围，但 DRM、损坏文件、缺少可用解码器的专有编码仍可能无法播放。格式后缀不保证内部编码可解码，未对所有格式、设备和系统版本逐项实测。
- 兼容缓存以 2 GB 为清理目标，当前使用的文件可能使缓存暂时超过该目标；单个准备文件最多 8 GB，并保留至少 512 MB 磁盘余量。空间不足时会停止准备并提示。
- TIFF 支持多页浏览，其他未实现分页的复合图片格式仍显示首幅；查看旋转不写回原文件。不提供编辑、删除、图库数据库、分享或云同步，也不提供外挂字幕管理。
- 只读取用户打开的本地媒体和所在文件夹；兼容播放写入本机缓存，不上传媒体，不修改原始文件。

更多格式示例、缓存与预览边界见 [FORMATS.md](FORMATS.md)。

## 从源码构建

需要 Xcode 或包含 Swift 编译器的 Command Line Tools。仓库与源码包已附带 Intel / Apple Silicon 通用版媒体工具，正常构建无需另外安装或下载第三方依赖。克隆或下载后，进入含有 `build.sh` 的仓库根目录即可构建，不需要原开发工作区的目录结构。

```bash
cd /path/to/LumaView
./build.sh
open ../LumaView.app
```

默认生成通用应用，`./build.sh --host` 只构建当前 Mac 架构。应用默认位于源码目录旁的 `LumaView.app`，可以通过 `LUMAVIEW_APP_PATH` 指定其他位置。构建和测试工作目录默认是仓库内的 `.build/`，可通过 `LUMAVIEW_WORK_ROOT` 覆盖；这些生成文件已由 `.gitignore` 排除。

测试构建使用 `LUMAVIEW_TEST_BUILD=1 ./build.sh --host`：生成独立的 `LumaView Tests` 应用，不声明文件打开方式，避免测试副本抢占正式安装版。界面测试脚本默认使用该模式；可以用 `LUMAVIEW_SKIP_TEST_BUILD=1` 和 `LUMAVIEW_TEST_APP_PATH` 指定已构建的应用。

FFmpeg 按 LGPL 2.1 或更新版本构建，静态链接的 dav1d 使用 BSD 2-Clause 许可证。对应源码归档、校验值和许可证随源码包提供。若要重建媒体工具，需要 Xcode Command Line Tools、Python 3、Meson 1.12.1 和 Ninja 1.13.2；可在 Python 虚拟环境中安装后运行 `./tools/build-media-tools.sh`。具体步骤和构建配置见 [ThirdParty/README.md](ThirdParty/README.md)。PostScript 使用独立的 Ghostscript 10.08.0（AGPL-3.0-or-later），随包附带许可证、完整对应源码和构建脚本；正常应用构建使用已附带的双架构组件，重建方法见 [Ghostscript 说明](ThirdParty/README-Ghostscript.md)。
