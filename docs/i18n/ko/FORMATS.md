LumaView 1.7.2의 형식 카탈로그는 이미지, 벡터 / 문서, 비디오, 오디오 72개 그룹입니다. 파일 검색과 기본 앱 선택용이며 모든 항목을 실측한 호환성 목록은 아닙니다. 같은 확장자라도 인코딩이 다를 수 있으며 실제 열기 가능 여부는 파일 내용, 시스템 기능, 내장 디코더에 달려 있습니다.

## 이미지

| 분류 | 형식 예 |
| --- | --- |
| 일반 이미지 | JPEG, PNG / APNG, GIF, TIFF, BMP, HEIC / HEIF, WebP |
| 기타 이미지 | AVIF, JPEG XL, JPEG 2000, ICO / CUR / ICNS, PSD / PSB, TGA, HDR / OpenEXR, Netpbm |
| 카메라 RAW | DNG, Canon CR2 / CR3 / CRW, Nikon NEF / NRW, Sony ARW / SR2 / SRF, ORF, RAF, RW2, PEF, SRW |

macOS ImageIO가 이미지를 디코딩합니다. 표는 카탈로그 후보 목록이며 특히 RAW, 신형 코덱, 전문 형식은 시스템 버전에 따라 지원이 달라집니다. 별도 RAW 디코더를 포함하지 않습니다. GIF 애니메이션과 TIFF 다중 페이지를 지원하며 페이지 처리를 구현하지 않은 다른 복합 이미지는 첫 장만 표시합니다.

PNG / APNG, GIF, PSD / PSB 등 래스터 이미지의 투명 영역은 모두 현재 배경을 드러내고 체크무늬를 추가하지 않습니다. 그림자는 실제 픽셀 투명도를 따라 생성하며 독립 소프트 마스크와 애니메이션의 각 프레임도 반영합니다. 빈 캔버스 가장자리에 사각형 그림자나 테두리를 붙이지 않습니다. 이 효과는 보기 전용이며 복사한 이미지는 원래 투명도를 보존하고 표시용 그림자를 포함하지 않습니다. PDF, SVG 등 벡터 문서는 아래 흰 종이 규칙을 따릅니다.

**Photoshop PSD / PSB:** 파일의 합성 이미지를 읽어 주 화면, 썸네일, 현재 표시 이미지 복사를 지원합니다. Photoshop 레이어를 재구성하거나 편집하지 않습니다. 호환 합성 이미지를 저장하지 않았다고 명시된 파일은 Photoshop에서 “호환성 최대화”를 켜고 다시 저장하도록 안내합니다. PSD / PSB는 파일 버전 1 / 2이며 [Adobe 형식 명세](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)에 따라 한 변 최대 크기는 각각 30,000 / 300,000픽셀입니다.

112개 기본 인코딩 조합의 디코딩을 검증했습니다. PSD와 PSB 각각 단일 / 추가 채널 회색조, 3채널 / 추가 채널 RGB의 8 / 16 / 32비트, CMYK의 8 / 16비트를 포함하며 각 조합에 무압축, PackBits RLE, ZIP, ZIP prediction을 검사했습니다. 실제 레이어 레코드를 포함한 회색조 / RGB 128개 샘플도 사용하여 8 / 16 / 32비트의 일반 사용자 alpha와 합성 투명도를 구분했습니다. 양수·음수 레이어 수, 전역 Lr16/Lr32 레코드, 합성 투명 표시, 무압축 / ZIP을 다룹니다. 300,000 × 128픽셀 PSB의 제한된 미리 보기, 주 화면, 썸네일도 검증했습니다. 이 행렬 샘플은 형식 명세로 생성했습니다. 1.7.1은 실제 레이어, 투명 합성, ICC를 가진 약 108–123 MiB PSB 3개로 주 화면과 썸네일을 추가 검증했지만 모든 Photoshop 내보내기 파일을 검증한 것은 아닙니다.

필름스트립은 Photoshop이 저장한 유효한 RGB JPEG 썸네일(리소스 1036)을 우선하며 인코딩, 크기, 종횡비, 길이를 검증합니다. 없거나 손상되거나 지원하지 않으면 합성 이미지로 대체합니다. 내장 미리 보기는 대개 작아서 필름스트립에만 쓰고 주 화면은 항상 호환 합성 이미지를 읽습니다. RLE는 최대 64 KiB 블록으로 읽어 각 압축 표식마다 파일을 읽지 않습니다. 블록 경계를 넘는 데이터와 긴 no-op 열도 취소 가능합니다.

ZIP, 고비트 RLE, 큰 이미지, 추가 채널 파일은 내장 행 단위 대체 로더를 사용한 뒤 ImageIO로 색을 해석합니다. 명시적 합성 투명 표시가 있으면 해당 투명도를 읽고 RGB / 회색조 합성 미리 보기의 흰 바탕을 제거해 별도 마스크를 붙입니다. 표시가 없으면 기본 색만 보여 저장된 선택 영역을 투명도로 오인하지 않습니다. 다중 alpha, 별색 채널, CMYK 투명도, 복잡한 마스크 조합은 완전 검증하지 않아 Photoshop 합성과 일치를 보장하지 않습니다. 대체 로더는 첫 번째 4 MiB 이하의 내장 ICC를 보존해 시스템에 넘깁니다. 유효한 ICC가 있는 작은 합성 데이터를 시스템이 거부하면 픽셀을 별도 디코딩하고 검증된 색 모델·성분이 일치하는 원래 ICC를 다시 붙이며 프로파일을 그냥 버리지 않습니다. 더 큰 프로파일은 건너뛰어 시스템 기본 색 해석을 사용할 수 있습니다. 32비트는 표시용 미리 보기이며 완전한 Photoshop HDR 톤 제어를 제공하지 않습니다. Lab, 인덱스 색, 듀오톤 등 특수 모드는 위 검증 행렬 밖이며 파일 구조와 시스템 디코딩에 따라 달라집니다. 1비트 PackBits는 별도로 작은 이미지의 네이티브 디코딩을 검사했습니다.

큰 이미지는 1.5억 픽셀 초과만으로 거부하지 않습니다. 메모리 예산에 맞춰 긴 변 최대 8192픽셀, 총 약 3200만 픽셀 이하의 미리 보기를 만들며 실제 크기는 더 작을 수 있습니다. 정보 패널은 원본 픽셀 크기·방향을 유지하고 축소 미리 보기임을 표시합니다. 배율은 원본 크기로 계산하며 미리 보기를 확대해도 미디코딩 원본 세부를 얻을 수 없습니다. 손상되거나 디코딩을 완료할 수 없는 파일은 여전히 오류를 냅니다.

## 벡터와 문서

| 형식 | 현재 동작 |
| --- | --- |
| SVG | 시스템 벡터 렌더러로 오프라인 렌더링하고 확대율에 맞춰 갱신합니다. 인식한 표준 SVG DTD 선언은 허용하지만 DTD는 읽지 않습니다. 사용자 정의 / 내부 DTD, 스크립트, 이벤트 처리, 외부 리소스를 거부하므로 복잡하거나 동적인 SVG 일부는 표시되지 않을 수 있습니다. |
| PDF | 다중 페이지 썸네일, 진행 막대, 페이지 번호, 초점, 키보드 페이지 이동을 지원합니다. 현재 배율로 그리고 자르기 상자와 페이지 방향을 유지하며 문서 편집은 없습니다. |
| AI | PDF 호환 데이터가 있으면 바로 표시하고 다중 페이지 / 아트보드를 지원합니다. 구형 PostScript AI는 내장 Ghostscript로 벡터 PDF 변환 후 표시하며 독점 Illustrator 데이터만 있는 파일은 열기를 보장하지 않습니다. |
| EPS / PostScript | 내장 Ghostscript 10.08.0이 전체 그리기 내용을 PDF로 바꾸고 경로, 텍스트, 내장 이미지를 유지해 벡터 캔버스에 표시합니다. 다중 페이지 PS를 지원합니다. 해석 실패 시 DOS EPS에 유효한 내장 TIFF가 있으면 래스터 미리 보기로 명시해 대체합니다. 비트맵은 원래 해상도에 제한되고 포함되지 않은 사용 불가 글꼴은 대체될 수 있습니다. |

주 캔버스는 PDF / SVG 벡터 원본을 유지하고 512픽셀 타일로 현재 배율의 보이는 영역을 그려 최대 3200% 확대를 지원합니다. 페이지 이동 시 화면에 맞는 완전한 페이지 바탕을 백그라운드에서 준비하고 전체 전환 후 원래 벡터 층이 현재 배율의 세부를 보충하므로 빈 영역이 타일별로 나타나지 않습니다. 바탕의 긴 변은 최대 4096픽셀이나 벡터 확대 선명도에는 영향을 주지 않습니다. 종이는 체크무늬 없이 흰색이며 내장 사진 등 비트맵은 원본 해상도에 제한됩니다. TIFF 각 페이지는 큰 이미지와 같은 제한된 래스터 미리 보기를 사용합니다. 잠금 해제하지 않은 암호화 PDF는 암호 입력을 제공하지 않아 직접 볼 수 없습니다. 렌더링은 원본을 수정하지 않습니다.

PDF / PDF 호환 AI는 오른쪽 클릭한 내장 비트맵 또는 현재 전체 페이지 복사를 지원합니다. 일반 XObject, 인라인 이미지, 중첩 Form, 클리핑, 페이지 방향을 지원합니다. 복잡한 마스크나 색 공간은 해당 가시 영역의 렌더링을 사용합니다. Pattern 안의 비트맵 같은 특수 구조나 탐색 예산 초과 페이지는 개별 이미지 복사가 불가능할 수 있습니다. 출력은 PNG/TIFF 비트맵으로 긴 변 최대 8192픽셀, 총 약 3200만 픽셀이고 원본은 변하지 않습니다.

## 비디오와 오디오

| 분류 | 카탈로그의 예 |
| --- | --- |
| 일반 비디오 컨테이너 | MP4 / M4V, MOV, MKV, WebM, AVI, FLV, WMV / ASF, MPEG, TS / M2TS, 3GP |
| 기타 비디오·비트스트림 | OGV, RM / RMVB, VOB, MOD / TOD, Motion JPEG, MXF, DV, NUT, NSV, AMV, Bink / Smacker, H.264, HEVC, VVC, IVF, Y4M 비트스트림 |
| 일반 오디오 | MP3, AAC, M4A, WAV, AIFF, CAF, FLAC, Ogg / Vorbis, Opus, WMA |
| 기타 오디오 | Speex, APE, WavPack, TTA, TAK, Shorten, AC-3 / E-AC-3 / TrueHD, DTS, AMR, AU / SND, RealAudio, DSD, MKA, Musepack, GSM / QCP, IFF Audio |

시스템 AVFoundation을 먼저 시도합니다. 직접 재생할 수 없으면 앱에 포함된 FFmpeg 9.0.2 / ffprobe를 사용하며 AV1 디코딩용 dav1d 1.5.3이 정적 링크되어 있습니다. 조건에 맞는 비디오는 영상 인코딩을 유지한 컨테이너 변경을 먼저 시도하고 여전히 불가하면 시스템이 재생할 수 있는 인코딩으로 바꿉니다. 오디오도 호환 준비를 통해 재생할 수 있습니다.

호환 준비는 네트워크를 끈 로컬 처리로 별도 설치가 필요 없습니다. 전체 파일을 먼저 처리해야 하므로 즉시 재생을 보장하지 않습니다. 진행률을 표시하고 파일 변경이나 창 닫기로 취소합니다. 트랜스코딩은 화질, 음질, 색 표현을 바꿀 수 있지만 원본은 유지합니다. 고해상도, 높은 프레임률, 복잡한 인코딩, 긴 파일의 속도는 기기에 달려 있습니다.

캐시는 2 GB를 목표로 자동 정리합니다. 사용 중인 파일은 남기므로 엄격한 총량 제한은 아닙니다. 준비 파일 하나는 최대 8 GB, 디스크 여유는 최소 512 MB가 필요하며 초과 시 중단하고 오류를 표시합니다. 다시 열 때 유효한 캐시를 재사용합니다.

DRM 보호, 손상, 포함되지 않은 외부 디코더, 독점 인코딩, 일부 특수 컨테이너는 재생 불가일 수 있습니다. 드문 형식도 카탈로그에 있지만 전부 사용 가능하다고 약속하지 않으며 모든 인코딩 조합을 개별 검증하지 않았습니다. 외부 자막 관리, 디스크 메뉴, 스트리밍 재생은 제공하지 않습니다.

## 오디오 표지와 파형

주 영역은 원본의 내장 표지를 우선하며 네이티브 메타데이터를 먼저 읽고 필요하면 내장 도구로 attached picture를 추출합니다. 표지는 긴 변 2048픽셀로 디코딩하며 실패하면 파형으로 대체합니다. 표지 없는 파일에 대해 인터넷에서 내려받거나 같은 폴더의 cover.jpg를 읽지 않습니다.

표지가 없으면 실제 디코딩 샘플에서 전체 오디오의 피크 포락선을 생성하고 최대 4096개 샘플 구간을 유지합니다. 각 PCM 버퍼의 크기도 제한해 긴 오디오 전체를 메모리에 올리지 않습니다. 호환 오디오는 준비된 로컬 재생 파일로 파형을 만듭니다. 파형은 전체 개요이며 실시간 스펙트럼이 아니고 생성 중에도 재생을 계속합니다. 파일 전환이나 창 닫기로 분석을 취소하며 늦은 결과는 현재 파일을 덮어쓰지 않습니다. 필름스트립 재생 시간은 별도로 비동기 읽으므로 각 파일을 먼저 선택할 필요가 없습니다. 오디오와 비디오 배지는 모두 `▶ 재생 시간`입니다.

## 기본 앱 설정

**LumaView → 기본 앱…** 또는 `⌘,`에서 연결할 형식을 그룹별로 선택하고 적용합니다. 열기, 재활성화, 설정 완료 시 실제 시스템 기본 연결을 읽으며 연결은 재시작 후에도 유지됩니다. 체크는 모든 유형이 현재 앱을 가리킴을, 가로선은 일부만 일치하거나 다른 LumaView 사본을 가리킴을 뜻합니다. 상단 “모든 형식 선택”은 검색에 영향받지 않고 모든 분류를 포함하며 그룹 “전체 선택”은 해당 분류만 고릅니다. 미적용 선택은 이번 초안이며 비우기로 이미 저장한 연결을 해제하지 않습니다. 시스템은 같은 유형 식별자의 여러 확장자를 한 종류로 취급해 함께 바꿀 수 있습니다.

결과를 시스템에서 다시 읽고 실패한 형식을 보고합니다. 취소는 미실행 변경만 중단하며 완료한 설정은 자동 복원하지 않습니다. 특정 형식을 되돌리려면 Finder “정보 가져오기 → 다음으로 열기 → 모두 변경”에서 원래 앱을 선택하세요.
