# Отчёт проверки LumaView 1.7.0

Дата: 2026-10-22 (Asia/Shanghai). Окружение этого цикла: macOS 15.7.9, x86_64. Приложение предназначено для macOS 13+; все четыре исполняемых файла универсальны для Intel / Apple Silicon.

## Изменения и фактические результаты

- Встроен Ghostscript 10.08.0: при открытии EPS, PostScript и старых PostScript AI в фоне создаётся PDF, сохраняющий векторные пути, текст и исходные встроенные изображения, затем передаётся существующему холсту. Устанавливать интерпретатор или вручную преобразовывать файлы не нужно; масштабирование, перемещение, поворот и страницы сохраняют текущие взаимодействия. Резервный TIFF используется, если векторное преобразование не удаётся, а файл предоставляет превью; растровый резерв не помечается как вектор.
- Проверенный исходный `sample-vector.eps` использует полное содержимое PostScript. Сканирование полученного PDF обнаружило **147,521 операций путей/градиентов, 59 текстовых операций, 160 вызовов XObject**. XObject считаются по PDF-операциям `Do` и могут быть изображениями или Form, поэтому не равны числу отдельных картинок. Проверено сохранение настоящего вектора; SHA-256 исходных EPS и `sample-vector.svg` сравнивались до и после, оригиналы не изменились.
- PostScript работает отдельным отменяемым процессом с Ghostscript SAFER и системной песочницей; вход копируется в выделенную временную папку, интерпретатор не может читать другие файлы пользователя, произвольно писать наружу и использовать внешние каналы. Пройдены проверки тайм-аута, отмены, совместного использования потребителями, повреждённого входа и инвалидирования кеша. Готовый результат публикуется атомарно, неполный PDF не используется для миниатюр. В реальном просмотрщике проверены EPS при 3200%, фокус вверх/вниз и листание влево/вправо многостраничного PS, а также отсутствие подмены текущего PNG устаревшим результатом при переключении во время преобразования.
- В группу Photoshop добавлен `.psb` вместе с `.psd` для обнаружения файлов, основного вида, миниатюр и ассоциаций. Читается совместимый композит, сохраняются исходные размеры; для больших файлов создаётся ограниченный предпросмотр по потребностям отображения. Проверены **112 комбинаций кодирования, 128 структурных образцов с маркерами прозрачности слоёв, 1 большой PSB, 13 повреждённых образцов**. Прозрачность определяется по числу слоёв и маркерам Lr16/Lr32, Mtrn/Mt16/Mt32; обычный дополнительный Alpha не принимается за прозрачность композита. Проверены значения прозрачных пикселей, удаление белой подложки, согласованность кодировок, отмена больших строк и интеграция основного вида/миниатюр.
- Диалог приложения по умолчанию читает реальные системные ассоциации при открытии, повторной активации и после пакетного применения. Система сохраняет их после перезапуска; неприменённый черновик не выдаётся за успех. Если все типы формата ведут к текущей копии, показывается галочка; если только часть или другая копия с тем же bundle ID — черта с поясняющей подсказкой. Очистка меняет только черновик и не отменяет системные ассоциации.
- Верхнее «Выбрать все форматы» выбирает изображения, векторы/документы, видео и аудио, включая не попавшие в поиск; запись происходит только после кнопки применения. Обнаружение, частичный успех, чтение ошибок, пересоздание контроллера, отличие черновика от реального состояния и полный выбор проверены с mock-бэкендом в памяти; системные приложения пользователя тестами не менялись.
- Новые строки настроек, PostScript и Photoshop охватывают все 16 языков; проверка основных строк и подстановок прошла.

## Проверка выпуска и установленной копии

Версия **1.7.0, build 12**. До составления отчёта сверены bundle ID, версия, build, полные списки файлов и SHA-256 в `outputs/LumaView.app` и `/Applications/LumaView.app`; содержимое совпадает. Все четыре исполняемых файла имеют обе архитектуры, обе копии проходят `codesign --verify --deep --strict`. Встроенный Ghostscript сообщает 10.08.0, локализации и ресурсы версии совпадают с исходниками, SHA-256 архива Ghostscript совпадает со списком. При сборке интерпретатор подписывается заново, поэтому подписанный бинарник не обязан побайтно совпадать с ещё не переподписанной исходной копией.

## Область действия и ограничения

Встроенный в EPS / PS растр остаётся ограничен исходным разрешением; полное преобразование внешних шрифтов/файлов и специального или повреждённого PostScript не гарантируется. PSD / PSB требует совместимого композита, не редактирует слои Photoshop и не восстанавливает отсутствующий композит; при отсутствии предлагается включить «Максимальная совместимость» и пересохранить. Исходный холст может быть больше отображаемого предпросмотра; ограниченный предпросмотр не означает полного декодирования всех исходных пикселей. Другие ограничения — в [FORMATS.md](../FORMATS.md).
