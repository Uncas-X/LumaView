LumaView は、画像、動画、音声、複数ページの文書を閲覧するためのネイティブ macOS アプリです。Picasa Photo Viewer の手軽な閲覧操作に着想を得ていますが、独自の名称とオリジナルアイコンを使用しており、Google とは関係ありません。編集や写真ライブラリの管理ではなく、ファイルの閲覧を中心に設計されています。

## ダウンロードとインストール

[LumaView for macOS](https://github.com/Uncas-X/LumaView/releases/latest/download/LumaView-macOS.zip) をダウンロードするか、[すべてのリリース](https://github.com/Uncas-X/LumaView/releases)をご覧ください。**macOS 13 以降**が必要です。Intel と Apple Silicon の両方に対応するユニバーサルアプリです。

ZIP を展開し、`LumaView.app` を「アプリケーション」フォルダに移動します。現在はローカルの ad-hoc 署名を使用しており、Apple の公証は受けていません。macOS によって起動がブロックされた場合は、入手元を確認したうえで「プライバシーとセキュリティ」の案内に従って許可してください。

## 基本的な使い方

ファイルやフォルダをドラッグ＆ドロップするか、`Cmd+O` で開きます。ファイルを一つ開くと、同じフォルダ内の前後のメディアも閲覧できます。フォルダの読み込みは現在の階層のみで、サブフォルダは検索しません。

- サムネイル列からファイルを切り替え、ズーム、移動、回転、全画面表示を操作できます。滑らかな画面切り替えと半透明のすりガラス風背景を備えています。
- PNG、GIF、PSD、PSB のラスター画像の透明部分は透明なまま表示し、影は内容の形に沿って描画します。文書のページには白い用紙背景を使います。PSD/PSB は保存済みの互換合成画像を表示し、レイヤーは編集しません。
- 動画と音声はまずシステムの再生機能を使い、必要に応じて同梱の FFmpeg で互換処理を行います。音声は埋め込みカバー画像を優先し、なければ波形を表示します。
- PDF、PDF 互換 AI、複数ページ TIFF のページ移動に対応します。SVG、対応する EPS/PS、旧形式 AI はベクター描画を使用します。EPS/PS は同梱の Ghostscript で処理しますが、埋め込みビットマップの精細さは元の解像度に制限されます。
- メイン画面を右クリックすると、別のアプリで開く、Finder で表示、画像・動画の現在フレーム・PDF ページ・対応する PDF 内の画像をコピーできます。
- 動画・音声の再生／一時停止と停止は、スライドショーとは別の操作です。形式ごとの既定アプリ設定と 16 言語の表示設定を用意しており、言語は初期状態でシステムに従います。

## キーボード操作

| キー | 操作 |
|---|---|
| `Cmd+O` | ファイルまたはフォルダを開く |
| `←` / `→` | フォーカス中のファイル列またはページ列で前後に移動 |
| `↑` / `↓` | 複数ページ文書でページ列／ファイル列へフォーカスを移す |
| ホイール、ピンチ、`+` / `-` | 拡大・縮小 |
| `0`；`1` | ウィンドウに合わせる；100% とウィンドウサイズを切り替える |
| `Cmd+R`；`F` | 回転；全画面表示 |
| `P`；`S` | メディアを再生／一時停止；停止 |
| `Cmd+4` | スライドショーを操作 |
| `Cmd+C` | 画像、現在のフレーム、ページをコピー |

**スペースキーは背景を切り替えます**。再生／一時停止のキーではありません。複数ページ文書では、フォーカスのある列の選択項目がオレンジ色、もう一方の列の選択項目が灰色の枠で表示されます。

## ソースからビルド

Xcode または Swift コマンドラインツールをインストールし、リポジトリのルートで実行します。

```bash
./build.sh
open ../LumaView.app
```

`./build.sh --host` は現在の Mac のアーキテクチャだけをビルドします。中間ファイルは既定で `.build/` に保存されます。作業ディレクトリは `LUMAVIEW_WORK_ROOT`、出力アプリのパスは `LUMAVIEW_APP_PATH` で変更できます。パスの基準はこの文書の場所ではなく、リポジトリのルートです。必要なメディアツールと対応するソース・ライセンスのアーカイブを同梱しています。

## 制限とプライバシー

ローカルファイルを読み込み、クラウドへアップロードせず、元のファイルを変更しません。エディター、レイヤー編集、ライブラリデータベース、クラウド同期はありません。大きな画像には縮小プレビューを使用する場合があり、そのプレビューで省略された細部はズームしても復元されません。互換処理ではファイル全体のローカル変換を終えてから再生する場合があり、ディスクキャッシュと処理時間が必要です。すべてのコーデックに対応するわけではなく、DRM 付き、破損、非対応のファイルは開けないことがあります。
