# سجل التحقق من LumaView 1.7.0

التاريخ: 2026-10-22 ‏(Asia/Shanghai). بيئة الجولة: macOS 15.7.9، ‏x86_64. يستهدف التطبيق macOS 13+، والملفات التنفيذية الأربعة شاملة لـ Intel / Apple Silicon.

## تغييرات هذه الجولة ونتائج القياس

- أُضمّن Ghostscript 10.08.0. عند فتح EPS وPostScript وPostScript AI القديم مباشرة يُولد PDF في الخلفية يحفظ المسارات المتجهة والنصوص والصور الأصلية المضمّنة ثم يُمرر للوحة الحالية. لا يلزم تثبيت مفسّر أو تحويل يدوي؛ وتبقى آليات التكبير والتحريك والتدوير والصفحات كما هي. يظل TIFF المضمّن بديلًا عند تعذر التحويل المتجه مع وجود معاينة في الملف، ولا يُوسم البديل النقطي كمتجه.
- أكد الاختبار استخدام كامل PostScript في المرفق الأصلي `sample-vector.eps`. كشف PDF الناتج **147,521 عملية مرتبطة بالمسارات / التدرجات، و59 عملية نص، و160 استدعاء XObject**. يُحسب XObject باستدعاءات PDF ‏`Do` وقد يشمل صورًا أو Form، فلا يساوي عدد الصور المستقلة. تأكد الحفاظ على محتوى متجه حقيقي؛ وقورنت SHA-256 لملف EPS الأصلي و`sample-vector.svg` قبل الاختبار وبعده ولم يتغير الأصلان.
- يستخدم PostScript عملية مستقلة قابلة للإلغاء وGhostscript SAFER وعزل عمليات النظام. يُنسخ الإدخال إلى مجلد مؤقت خاص؛ ولا يستطيع المفسّر قراءة ملفات المستخدم الأخرى أو كتابة ملفات خارجية اعتباطيًا أو استخدام أنابيب خارجية. اجتازت المهلة والإلغاء وإعادة الاستخدام متعدد المستهلكين والإدخال التالف وإبطال التخزين اختباراتِها. تُنشر النتائج المكتملة ذريًا ولا تُملأ المصغرات بـ PDF جزئي. اختُبر في العارض الفعلي تكبير EPS المتجه 3200%، وتركيز أعلى / أسفل وتنقل يمين / يسار في PS متعدد الصفحات، وعدم استبدال النتائج القديمة العرض بعد التحول إلى PNG أثناء التحويل.
- أُضيف `.psb` إلى مجموعة Photoshop مع `.psd` لاكتشاف الملفات والصورة الرئيسية والمصغرات وإعداد الافتراضي. تُقرأ الصورة المركبة المتوافقة مع حفظ أبعاد اللوحة الأصلية، وتُنشأ معاينات محدودة للكبير حسب حاجة العرض. اكتمل التحقق من **112 تركيبة ترميز، و128 عينة بنية بعلامات شفافية طبقات، و1 ملف PSB كبير، و13 عينة تالفة**. تُحدد شفافية التركيب بعدد الطبقات وعلامات Lr16/Lr32 وMtrn/Mt16/Mt32، فلا تُخلط قنوات Alpha الإضافية العادية بها. تشمل الاختبارات قيم البكسلات الشفافة وإزالة الأساس الأبيض وتوافق الترميزات وإلغاء الصفوف الكبيرة وتكامل الصورة الرئيسية / المصغرة.
- تقرأ نافذة الافتراضي ارتباطات النظام الحقيقية عند كل فتح وإعادة تنشيط وبعد الإعداد الجماعي. الارتباطات نفسها تبقى بعد إعادة التشغيل، ولا تُعد مسودات غير مطبقة نجاحًا. تظهر علامة اختيار إذا طابقت جميع أنواع الصيغة التطبيق الحالي، وخط مع شرح إذا طابق بعضها أو أشار إلى نسخة أخرى لها bundle ID نفسه. يمسح التفريغ المسودة فقط ولا يلغي الارتباطات.
- يحدد «تحديد كل الصيغ» العلوي الصور والمتجهات / المستندات والفيديو والصوت دفعةً واحدة، بما فيها خارج البحث؛ ولا تُكتب الارتباطات حتى ضغط زر التطبيق. اختُبرت القراءة والنجاح الجزئي والفشل المقروء وإعادة إنشاء المتحكم والفرق بين المسودة والحالة الفعلية والتحديد الكامل بواجهة mock في الذاكرة؛ ولم تتغير تطبيقات النظام الافتراضية للمستخدم.
- غطّت النصوص الجديدة للإعدادات وPostScript وPhotoshop كل اللغات الـ16، واجتازت النصوص الأساسية ومواضع التنسيق التحقق.

## فحص مجلد الإصدار والنسخة المثبتة

الإصدار **1.7.0، build 12**. قبل التقرير قورنت `outputs/LumaView.app` و`/Applications/LumaView.app` في bundle ID والإصدار وbuild وقائمة الملفات الكاملة وSHA-256؛ وتطابق المحتوى. اجتازت التنفيذيات الأربعة فحص المعماريتين، واجتاز التطبيقان `codesign --verify --deep --strict`. أبلغ Ghostscript الداخلي عن 10.08.0، وطابقت موارد اللغة والإصدار المصدر، وطابقت SHA-256 لأرشيف Ghostscript القائمة المرفقة. يعيد البناء توقيع المفسّر؛ لذلك لا يُشترط تطابق بايتات الملف الموقّع مع النسخة غير المعاد توقيعها في المصدر.

## النطاق والحدود

تظل الصور النقطية الأصلية في EPS / PS محدودة بدقتها. لا يُضمن التحويل الكامل للخطوط أو موارد الملفات الخارجية أو PostScript الخاص أو التالف. تعتمد معاينة PSD / PSB على الصورة المركبة المتوافقة ولا تحرر طبقات Photoshop أو تعيد بناء تركيب مفقود؛ بل تطلب إعادة الحفظ مع «زيادة التوافق». قد تكون اللوحة الأصلية أكبر من المعاينة المعروضة، ولا توصف المعاينة المحدودة بأنها فك كامل لكل بكسلات المصدر. راجع [FORMATS.md](../FORMATS.md) للقيود الأخرى.
