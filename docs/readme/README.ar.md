LumaView تطبيق أصلي لنظام macOS لعرض الصور والفيديو والصوت والمستندات متعددة الصفحات. يستلهم أسلوب التصفح السريع من Picasa Photo Viewer، لكنه يحمل اسماً وأيقونة مستقلين ولا يرتبط بشركة Google. يركز التطبيق على مشاهدة الملفات، وليس على تحرير الصور أو إدارة مكتبة للصور.

## التنزيل والتثبيت

**الإصدار 1.7.2، رقم البناء 14.** يتطلب macOS 13 أو أحدث. يتوفر إصدار موحّد لأجهزة Mac المزودة بمعالجات Intel وApple Silicon.

1. نزّل [LumaView لنظام macOS](https://github.com/Uncas-X/LumaView/releases/latest/download/LumaView-macOS.zip). يمكنك أيضاً تصفح [جميع الإصدارات](https://github.com/Uncas-X/LumaView/releases).
2. فك ضغط الملف واسحب `LumaView.app` إلى مجلد التطبيقات.
3. افتح التطبيق. يستخدم توقيعاً محلياً من نوع ad hoc ولم يحصل على توثيق Apple. بعد التحقق من مصدر التنزيل، قد تحتاج إلى السماح بفتحه من قسم **الخصوصية والأمن** في إعدادات macOS.

## التصفح والميزات

اسحب ملفاً أو مجلداً إلى النافذة، أو اضغط **Cmd+O**. عند فتح ملف واحد، يمكنك التنقل بين ملفات الوسائط الأخرى الموجودة في المجلد نفسه. يفحص التطبيق المستوى الحالي فقط ولا يتصفح المجلدات الفرعية تلقائياً.

- استخدم شريط الصور المصغرة لاختيار الملفات. يتوفر التكبير والتحريك والتدوير وملء الشاشة، مع انتقالات سلسة وخلفية شبه شفافة بتأثير الزجاج المصنفر.
- تبقى المناطق الشفافة في PNG وGIF وPSD وPSB شفافة، وتتبع الظلال شكل المحتوى. تظهر صفحات المستندات على ورق أبيض. يعرض PSD وPSB الصورة المركبة المحفوظة للتوافق، وليس الطبقات المنفصلة.
- يستخدم الصوت والفيديو التشغيل الأصلي أولاً. يتيح FFmpeg المضمّن تشغيل صيغ إضافية، لكنه قد يحتاج إلى تجهيز الملف كاملاً محلياً قبل بدء التشغيل. يعرض الصوت صورة الغلاف المضمّنة أو الشكل الموجي عند عدم وجودها. أزرار تشغيل الوسائط وإيقافها مؤقتاً وإيقافها مستقلة عن عرض الشرائح.
- يمكنك التنقل بين صفحات PDF وملفات AI المتوافقة مع PDF وTIFF متعدد الصفحات. يتوفر العرض المتجهي لملفات SVG وEPS/PS المدعومة وAI القديمة. يعالج Ghostscript المضمّن ملفات EPS/PS؛ وتظل الصور النقطية المضمّنة محدودة بدقتها الأصلية.
- تتيح قائمة النقر بزر الفأرة الأيمن الفتح بتطبيق آخر، والإظهار في Finder، ونسخ الصورة أو الإطار الحالي للفيديو أو صفحة PDF أو صورة مضمّنة مدعومة داخل PDF.

في الإعدادات، يمكنك اختيار الصيغ التي يفتحها LumaView افتراضياً ولغة الواجهة. يدعم التطبيق 16 لغة ويتبع لغة النظام افتراضياً.

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
| --- | --- |
| Cmd+O | فتح ملف أو مجلد |
| ← / → | الملف أو الصفحة السابقة/التالية بحسب موضع التركيز |
| ↑ / ↓ | نقل التركيز بين الصفحات والملفات في المستندات متعددة الصفحات |
| عجلة الفأرة / إيماءة القرص / + / − | تغيير التكبير |
| 0 / 1 | ملاءمة النافذة / التبديل بين ‎100%‎ والملاءمة |
| Cmd+R | تدوير |
| F | التبديل إلى ملء الشاشة أو الخروج منه |
| P / S | تشغيل الوسائط أو إيقافها مؤقتاً / إيقافها |
| Cmd+4 | التحكم في عرض الشرائح |
| Cmd+C | نسخ صورة أو إطار أو صفحة |

**مفتاح المسافة يغيّر الخلفية؛ ولا يتحكم في التشغيل أو الإيقاف المؤقت.**

## البناء من المصدر

ثبّت Xcode أو أدوات سطر أوامر Swift. يتضمن المستودع أدوات الوسائط اللازمة وأرشيفات الشيفرة المصدرية والتراخيص الخاصة بها. نفّذ الأوامر التالية من جذر المستودع، وليس من مجلد هذا الدليل:

```bash
./build.sh
open ../LumaView.app
```

يبني `./build.sh --host` التطبيق لمعمارية جهاز Mac الحالي فقط. تُحفظ الملفات الناتجة افتراضياً في `.build/`. يغيّر `LUMAVIEW_WORK_ROOT` هذا المجلد، ويغيّر `LUMAVIEW_APP_PATH` مسار التطبيق الناتج.

## القيود والخصوصية

يقرأ التطبيق الملفات المحلية دون رفعها إلى السحابة أو تعديل أصولها. لا يتضمن محرر صور أو تحرير طبقات أو قاعدة بيانات لمكتبة أو مزامنة سحابية. قد تُعرض الصور الكبيرة بمعاينات منخفضة الدقة ضمن حدود الذاكرة؛ ولا يعيد التكبير التفاصيل التي حُذفت من المعاينة. لا يوجد ضمان لتشغيل جميع برامج الترميز، وقد تتعذر قراءة الملفات المحمية بتقنية DRM أو التالفة أو غير المدعومة. تستخدم التحويلات ذاكرة تخزين مؤقت على القرص المحلي وقد تستغرق وقتاً.
