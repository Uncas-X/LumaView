LumaView 1.7.2 的格式目錄包含 72 組圖片、矢量 / 文檔、影片和音訊選項。目錄用於發現檔案和選擇預設打開方式，不是逐項實測的兼容性清單。副檔名相同的檔案可能使用不同編碼；最終能否打開由檔案內容、系統能力和內置解碼器決定。

## 圖片

| 類別 | 格式示例 |
| --- | --- |
| 常見圖片 | JPEG、PNG / APNG、GIF、TIFF、BMP、HEIC / HEIF、WebP |
| 其他圖片 | AVIF、JPEG XL、JPEG 2000、ICO / CUR / ICNS、PSD / PSB、TGA、HDR / OpenEXR、Netpbm |
| 相機 RAW | DNG、Canon CR2 / CR3 / CRW、Nikon NEF / NRW、Sony ARW / SR2 / SRF，以及 ORF、RAF、RW2、PEF、SRW |

圖片由 macOS ImageIO 解碼。上表列出格式目錄中的候選項，尤其 RAW、新型圖片編碼和專業格式的支援隨系統版本變化。應用不單獨捆綁 RAW 解碼器。GIF 支援動畫；TIFF 支援多頁瀏覽，其他尚未實現分頁的復合圖片格式只顯示首幅。

PNG / APNG、GIF、PSD / PSB 等柵格圖片的透明區域統一露出查看器當前背景，不添加灰白格。陰影依據實際像素透明度形成，覆蓋獨立軟蒙版與動圖每一幀，不在空白畫布邊緣添加矩形陰影或邊框。此效果僅用於查看，複製的圖片保留原有透明度且不帶顯示陰影。PDF、SVG 等矢量文檔沿用下文的白色紙面規則。

**Photoshop PSD / PSB：**讀取檔案內的合成圖，支援主圖、縮略圖和複製當前顯示的圖片，不重建或編輯 Photoshop 圖層。檔案若明確未保存兼容合成圖，會提示在 Photoshop 中開啓“最大兼容性”後重新保存。PSD / PSB 對應檔案版本 1 / 2；按 [Adobe 格式規範](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)，單邊尺寸分別不超過 30,000 / 300,000 像素。

當前通過 112 個基礎編碼組合的解碼驗證：PSD 和 PSB 各覆蓋單通道/帶額外通道的灰度、三通道/帶額外通道的 RGB 的 8 / 16 / 32 位，以及 CMYK 的 8 / 16 位；每種組合覆蓋未壓縮、PackBits RLE、ZIP、ZIP prediction。另有 128 個包含實際圖層記錄的灰度/RGB樣例，驗證 8 / 16 / 32 位下普通使用者 alpha 與合成透明度的區分，覆蓋正負圖層數、全局 Lr16/Lr32 記錄、合成透明標記，以及未壓縮/ZIP 兩種編碼。還驗證了 300,000 × 128 像素 PSB 的有界預覽、主圖和縮略圖流程。上述矩陣樣例由格式規範生成。1.7.1 另用三份約 108–123 MiB 的真實帶圖層、透明合成與 ICC 的 PSB 驗證主圖和縮略圖；這些檢查不能代表任意 Photoshop 導出檔案都已驗證。

膠片帶優先讀取 Photoshop 保存的有效 RGB JPEG 縮略圖（資源 1036），會校驗編碼、尺寸、長寬比和長度；缺失、損壞或不支援時回退到合成圖。內嵌預覽通常較小，只用於膠片帶，主畫面始終讀取兼容合成圖。RLE 按最多 64 KiB 的塊讀取，避免為每個壓縮標記發起檔案讀取，跨塊資料和長串 no-op 仍支援取消。

ZIP、高位元深度 RLE、大圖及帶額外通道的檔案使用內置逐行後備讀取，再交由 ImageIO 完成色彩解釋。有明確合成透明標誌時讀取相應透明度，RGB/灰度會解除合成預覽的白底並附加獨立遮罩；未聲明合成透明時只顯示基礎色彩，不把保存的選區誤作透明。多 alpha、專色通道、CMYK 透明度、複雜蒙版等組合未作完整驗證，不能保證與 Photoshop 的圖層合成一致。後備讀取保留第一個不超過 4 MiB 的內嵌 ICC 配置，並交給系統處理。若系統拒絕含有效 ICC 的小尺寸合成資料，則分開解碼像素並重新附加經校驗、模型與分量一致的原 ICC，不直接丟棄配置；更大的配置會跳過，可能按系統預設色彩解釋。32 位資料用於顯示預覽，不提供完整的 Photoshop HDR 色調控制。Lab、索引色、雙色調和其他特殊模式不在上述實測矩陣內，能否打開仍取決於檔案結構與系統解碼能力；1 位 PackBits 另有小圖原生解碼檢查。

大圖不會僅因超過 1.5 億像素而拒絕打開。加載器按記憶體預算生成預覽，最長邊最多 8192 像素、總量最多約 3200 萬像素，實際可能更低。資訊面板保留原始像素尺寸和方向，並標明下採樣預覽。縮放比例依據原始尺寸計算；放大預覽無法得到尚未解碼的原圖細節。損壞或無法完成解碼的檔案仍會報錯。

## 矢量與文檔

| 格式 | 當前行為 |
| --- | --- |
| SVG | 使用系統矢量渲染器離線繪制，並隨縮放更新；允許已識別的標準 SVG DTD 聲明但不加載 DTD；拒絕自定義/內部 DTD、腳本、事件處理和外部資源，部分複雜或動態 SVG 可能無法顯示。 |
| PDF | 支援多頁縮略圖、進度條、頁碼、焦點與鍵盤翻頁；按當前縮放繪制，保留裁切框和頁面方向；不提供文檔編輯。 |
| AI | 含 PDF 兼容資料時直接顯示，支援其中的多個頁面 / 畫板；舊版 PostScript AI 由內置 Ghostscript 轉為矢量 PDF 後顯示；僅含專有 Illustrator 資料的檔案仍不保證可打開。 |
| EPS / PostScript | 內置 Ghostscript 10.08.0 將完整繪圖內容轉換為 PDF，保留路徑、文本與嵌入圖像，再由矢量畫布顯示；支援多頁 PS。若解釋失敗且 DOS EPS 含有效內嵌 TIFF，可回退並注明柵格預覽。位圖仍受原分辨率限制，未嵌入且不可用的字體可能替換。 |

主畫布保留 PDF / SVG 的矢量源，用 512 像素分塊按當前縮放繪制可見區域，支援最高 3200% 縮放。翻頁時先在後台準備與屏幕相適應的完整頁面底圖，整頁過渡後由原始矢量層補充當前縮放的細節，避免看到未繪制區域逐塊出現。底圖最長邊最多 4096 像素，不影響矢量層的放大清晰度。文檔紙面為純白色，不顯示棋盤格；內嵌照片等位圖的細節受源分辨率限制。TIFF 每一頁使用與大圖相同的有界柵格預覽。加密且未解鎖的 PDF 不提供密碼輸入，無法直接查看。渲染不改寫原始檔案。

PDF / PDF 兼容 AI 支援右鍵複製點到的內嵌位圖，或複製當前整頁。支援常見 XObject、內聯圖片、嵌套 Form、裁剪與頁面方向。複雜蒙版或色彩空間使用對應可見區域的渲染結果；Pattern 圖案內的位圖等特殊結構、超出掃描預算的頁面，可能無法單獨複製內嵌圖片。複製輸出為 PNG/TIFF 位圖，最長邊至多 8192 像素、總量約 3200 萬像素；原檔案不改變。

## 影片與音訊

| 類別 | 格式目錄中的示例 |
| --- | --- |
| 常見影片容器 | MP4 / M4V、MOV、MKV、WebM、AVI、FLV、WMV / ASF、MPEG、TS / M2TS、3GP |
| 其他影片與碼流 | OGV、RM / RMVB、VOB、MOD / TOD、Motion JPEG、MXF、DV、NUT、NSV、AMV、Bink / Smacker，以及 H.264、HEVC、VVC、IVF、Y4M 碼流 |
| 常見音訊 | MP3、AAC、M4A、WAV、AIFF、CAF、FLAC、Ogg / Vorbis、Opus、WMA |
| 其他音訊 | Speex、APE、WavPack、TTA、TAK、Shorten、AC-3 / E-AC-3 / TrueHD、DTS、AMR、AU / SND、RealAudio、DSD、MKA、Musepack、GSM / QCP、IFF Audio |

先嘗試系統 AVFoundation 播放。不能直接播放時使用隨應用提供的 FFmpeg 9.0.2 / ffprobe，包含靜態鏈接的 dav1d 1.5.3 以解碼 AV1。符合條件的影片先嘗試保留影片編碼並更換容器；仍不能播放時再轉為系統可播放的編碼。音訊也可通過兼容準備播放。

兼容準備在本地完成，禁用網路功能，無需額外安裝。它需要先處理完整檔案，不能保證即時開始播放。介面顯示準備進度，切換檔案或關閉窗口會取消。轉碼可能改變畫質、音質或色彩表現；原始檔案保持不變。高分辨率、高幀率、複雜編碼和長檔案的速度取決於設備。

快取會自動清理，以 2 GB 為目標；正在使用的檔案會保留，所以該數值不是嚴格的總量上限。單個準備檔案最多 8 GB，磁碟可用空間需保留至少 512 MB，超過限制會停止並顯示錯誤。重復打開可復用有效快取。

DRM 保護、損壞檔案、未包含的外部解碼器、專有編碼及部分特殊封裝可能無法播放。目錄包含少見格式，但不承諾全部可用，也未逐一驗證每個編碼組合。當前不提供外掛字幕管理、光盤選單或流媒體播放。

## 音訊封面與波形

主顯示區域優先採用原檔案內嵌封面，先讀取原生元資料，必要時由內置工具提取 attached picture。封面按最長邊 2048 像素解碼；無法解碼的封面回退為波形。未內嵌封面的檔案不從網路下載封面，也不讀取同目錄的 cover.jpg。

無封面時從實際解碼採樣生成整段音訊的峰值包絡，保留最多 4096 個採樣區間，每批 PCM 緩衝有界，長檔案也不會把整段音訊加載到記憶體。兼容音訊使用已準備好的本地播放檔案生成波形。波形是整段概覽，不是實時頻譜；生成期間播放仍可繼續。切換檔案或關閉窗口會取消分析，遲到結果不會覆蓋當前檔案。膠片帶時長獨立異步讀取，無需先選中每個檔案；音訊與影片的角標均為 `▶ 時長`。

## 預設應用設定

通過 **LumaView → 預設打開方式…** 或 `⌘,`，按組勾選需要關聯的格式，再執行設定。每次打開、重新激活和設定完成後讀取系統實際預設關聯；系統關聯跨重啓保存。勾選表示全部類型命中當前應用，橫線表示部分命中或指向另一個 LumaView 副本。頂部“全選所有格式”覆蓋所有類別，不受搜索影響；分組“全選”可只選當前類別。未應用的勾選只是本次草稿，清空不會取消已經成功寫入的系統關聯。系統可能將使用同一類型標識的多個副檔名視為一種檔案類型，因此某些副檔名會一起更改。

介面回讀系統結果並報告未成功的格式。取消只停止尚未執行的更改；已完成的設定不會自動撤銷。需要恢復某種格式時，可在 Finder 的“顯示簡介 → 打開方式 → 全部更改”中選擇原應用。
