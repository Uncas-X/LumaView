**[macOS アプリをダウンロード](https://github.com/Uncas-X/LumaView/releases/latest/download/LumaView-macOS.zip)** · [リリースと更新情報](https://github.com/Uncas-X/LumaView/releases)

macOS 13+ に対応し、1 つのパッケージで Intel と Apple Silicon をサポートします。ZIP をダウンロードして展開し、`LumaView.app` を「アプリケーション」にドラッグしてインストールします。

Picasa Photo Viewer の手軽な閲覧操作を参考にした macOS ネイティブのメディアビューアです。同じフォルダ内の閲覧、ズーム、ドラッグ、回転、フィルムストリップ、フルスクリーン、スライドショーに対応します。1.5 では音声のカバー画像と実サンプルによる波形、複数ページ文書の操作、ズームに合わせて描画するベクトルキャンバス、既定でシステムに従う多言語設定を追加しました。独自の名前とオリジナルアイコンを採用しており、旧 Picasa の全機能や操作と完全に一致するとはしていません。

1.7.2 では画像の透明部分の表示を統一しました。PNG、GIF、PSD / PSB などのラスター画像は現在の閲覧背景を透過し、影は実際の画像の輪郭と透明度に従います。市松模様や、透明なキャンバス全体に付く長方形の影は表示しません。PDF などの文書は引き続き白い紙面で表示します。

1.7.1 の PSD / PSB プレビュー最適化も維持しています。フィルムストリップは有効な埋め込み JPEG を優先し、メイン画像は実際の互換合成画像をデコードします。RLE はブロック単位で読み取り、一部の ICC プロファイル付き小サイズ合成画像でサムネイルを生成できない問題も修正しました。

## 使用方法とインストール

macOS 13 以降が必要です。Intel と Apple Silicon に対応します。

1. [Releases](https://github.com/Uncas-X/LumaView/releases) から `LumaView-macOS.zip` をダウンロードし、展開後に `LumaView.app` を「アプリケーション」フォルダへドラッグして開きます。
2. 画像、動画、音声、フォルダをドラッグするか、`⌘O` でファイルを選択します。1 ファイルを開くと同じフォルダ内のメディアを一覧化し、複数選択時は選択したファイルを閲覧します。フォルダは直下のみを走査し、サブフォルダを再帰走査しません。
3. Finder でファイルを右クリックし、「このアプリケーションで開く → LumaView」からも開けます。

ローカルビルドはアドホック署名で、Apple の公証を受けていません。他の Mac でダウンロードしたコピーが Gatekeeper に遮断された場合、入手元を確認したうえでシステムの「プライバシーとセキュリティ」から開くことを許可できます。

## デフォルトのアプリケーション

**LumaView → デフォルトのアプリケーション…**、`⌘,`、または「その他」メニューから設定を開きます。形式は画像、ベクトル / 文書、動画、音声に分類され、検索して選択した後「選択した形式のデフォルトに設定」を押します。ダイアログを開いたとき、アプリが再びアクティブになったとき、設定完了時に実際のシステム関連付けを読み取ります。チェックはそのグループの全形式が現在の LumaView に関連付けられていることを示し、横線は一部のみ、または別のコピーに関連付けられていることを示します。システムの関連付けは再起動後も残ります。未適用の選択を成功済みとして表示しません。上部の「すべての形式を選択」は検索条件に関係なく画像、ベクトル文書、動画、音声をすべて対象にし、分類内の一括選択も可能です。クリアは今回の選択だけを解除し、既存のシステム関連付けを解除しません。

設定中は進捗を表示し、各結果をシステムから再取得します。キャンセルすると後続の変更を止めますが、完了した変更は残ります。形式一覧は選択可能な関連付けであり、すべての内部コーデックやファイルを実機検証した一覧ではありません。詳細は[形式とプレビューの説明](FORMATS.md)を参照してください。

## 閲覧と再生

最初にファイルを開くと、現在の画面の利用可能領域へウィンドウが広がります。`F` でフルスクリーンになります。下部のフィルムストリップで直接ファイルを切り替えられます。画像領域にマウスをしばらく置くと操作バーが隠れ、マウスを動かすと再表示します。

1.5.2 では大きなフォルダを連続閲覧した際にサムネイルが空白になったり点滅したりする問題を修正しました。表示中のサムネイルを独立して保持し、画面外の読み込みは速やかにキャンセルします。フォルダを切り替えた後の古い結果は新しい一覧へ書き込みません。デコードできないファイルは安定したプレースホルダーを表示し、その範囲へ戻ると再試行できます。

画像と動画はズーム、ドラッグ、回転、フルスクリーンに対応します。ウィンドウ、画像切り替え、ズーム、回転には短い滑らかなトランジションを使い、連続操作で中断できます。システムの「視差効果を減らす」を有効にすると、これらの独自トランジションを停止しますが、アニメーション画像は通常どおり再生します。既定は半透明のすりガラス背景で、スペースキーで、すりガラス、暗色、明色を切り替えます。

ラスター画像の透明領域は統一した規則で現在の背景を表示します。影は内容のあるピクセルだけに従い、半透明の縁は透明度を維持します。GIF / APNG の再生時は影も各フレームに合わせて変化します。画像のコピーは元の透明ピクセルを保持し、ビューアの背景や影を含みません。

音声・動画の再生、停止、シーク、音量コントロールはフィルムストリップの上にあります。開くと自動再生し、終了時は末尾に止まり、`P` で再再生できます。`S` は停止して先頭へ戻ります。下のスライドショーボタンは音声・動画の再生ボタンとは独立しています。`⌘4` で連続再生を開始すると、画像は設定間隔で切り替え、音声・動画は再生終了後に切り替えます。音声・動画だけを再生しても次のファイルへ自動移動しません。

macOS のネイティブ再生を優先します。直接再生できない場合は、内蔵のユニバーサル版 FFmpeg 9.0.2 と dav1d 1.5.3 でローカルに互換ファイルを準備します。条件が合う場合はまずコンテナ変更を試し、次にトランスコードを試します。別のプレーヤー、Homebrew、コーデックパックは不要で、ネットワークにもアクセスしません。互換再生はファイル全体の準備を待つ必要があり、その間は進捗を表示します。ファイルの切り替えやウィンドウを閉じる操作でキャンセルできます。長い動画は初回準備に時間と追加のディスク容量が必要になる場合があります。

`C` または「その他」メニューで、循環閲覧、ホイール動作、背景クリックで閉じる設定、フィルムストリップ、並べ替え、スライドショー間隔（2、3、5、8、10 秒）を設定できます。ホイールは既定でズームし、`Ctrl` を押している間はファイル閲覧に切り替わります。既定を閲覧にした場合は `Ctrl` で一時的にズームします。「画像外の背景をクリックして閉じる」は既定で有効です。これらの設定はローカルに保存します。

## 右クリックメニューとコピー

メイン画面を右クリック（または Ctrl クリック）すると、「このアプリケーションで開く → アプリ / その他のアプリ…」や「Finder に表示」を選べます。「このアプリケーションで開く」は今回だけに適用し、デフォルトの関連付けを変えません。デコードできないファイルにも、この 2 つの操作を使えます。

- 画像：「画像をコピー」を選びます。現在の表示の回転と透明ピクセルを保持し、現在デコードされている画像全体をコピーします。ツールバーやズーム後の画面領域のスクリーンショットではありません。
- 動画：「現在のフレームをコピー」を選びます。右クリックメニューを開いた時点に対応するフレームをコピーし、動画の向きと表示の回転を保ちます。再生位置や再生状態は変更しません。
- PDF / PDF 互換 AI：ページ内のビットマップを右クリックして「この画像をコピー」、または「現在のページをコピー」を選べます。ズーム、ドラッグ、回転後も実際のクリック位置で判定します。通常の文字やベクトル領域は画像として扱いません。複雑なマスクや色空間では画像領域の見た目をコピーするため、重なった文字を含む場合があります。1 枚の画像としてスキャンされたページはスキャン画像全体をコピーします。
- `⌘C` は現在の画像、動画フレーム、文書ページをコピーします。音声には画像コピーを提供しません。クリップボードには PNG と TIFF を渡し、ファイル / ページの切り替えや閉じた後に古いコピー結果で上書きしません。

文書や埋め込み画像のコピーは最長辺 8192 ピクセル、約 3200 万ピクセルを上限とするビットマップを生成し、PDF/SVG のベクトル命令はクリップボードへ渡しません。大きな画像を制限付きプレビューで表示している場合は、そのプレビューをコピーします。PDF の画像走査には複雑度の上限があります。パターン塗りの画像など特殊な構造は個別選択できない場合がありますが、現在のページのコピーは可能です。

標準 SVG 1.0/1.1 ヘッダーはオフラインで解析し、外部 DTD を読み込みません。1.7 は Ghostscript 10.08.0 を内蔵し、EPS / PostScript と旧 PostScript AI を、パス、文字、埋め込み画像を保持する PDF へ変換します。メイン画面はズームに合わせてベクトルを再描画し、複数ページの PS は既存のページ操作を使います。追加ソフトは不要です。変換に失敗しても有効な埋め込み TIFF を含む EPS はプレビューへフォールバックでき、TIFF と明示します。元のビットマップがベクトルに変わるわけではありません。

## 音声、文書、言語

音声に埋め込みカバーがある場合はメイン画面に優先表示します。利用可能なカバーがない場合は実サンプルを非同期解析し、音声全体の波形を表示します。解析中はプレースホルダーを出し、波形を待たずに再生できます。音声と動画のフィルムストリップ右下は、同じフォント、背景色、位置で `▶ 再生時間` を表示します。未取得時は `▶ –:––` です。カバーは埋め込みメタデータからのみ取得し、ネットワークや同じディレクトリの画像を探しません。

PDF、PDF 互換 AI、複数ページ TIFF はページ内閲覧に対応します。小さめのページサムネイル、ページ進捗バー、現在ページ / 総ページ数をファイルのフィルムストリップの上に表示します。`↑` はページ、`↓` はファイルにフォーカスします。現在の層の選択サムネイルはオレンジの枠でフォーカスを示し、もう一方は灰色の枠で選択を保持します。「ページ / ファイル」ラベルは表示しません。`←` / `→`、`J` / `K`、`Home` / `End` は現在のフォーカスを操作します。各層をクリックしてもフォーカスが移ります。最初 / 最後のページで止まり、別のファイルへ意図せず移動しません。下部の前 / 次ファイルボタンは常にファイルを切り替えます。ファイルのフィルムストリップを隠してもページ操作は残ります。

PDF、SVG、PDF 互換 AI は、固定プレビューを拡大せず、元のベクトル命令で現在のズームに応じた可視領域を描画します。文書の透明部分は市松模様のない白い紙面です。ページ切り替え時は新しいページ全体の準備を待ってから全体をフェードインし、背景でのベクトル詳細描画による空白タイルの出現を防ぎます。ファイル内の写真などのビットマップには元の解像度の制約が残ります。

**LumaView → 言語…** または「その他」メニューで言語を選びます。既定はシステムに従い、簡体字中国語、繁体字中国語、英語、日本語、韓国語、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語、ロシア語、アラビア語、ヒンディー語、トルコ語、オランダ語、ポーランド語をサポートします。アプリメニュー、ツールチップ、ページ操作、設定画面は即時更新し、選択をローカルに保存します。未対応のシステム言語は英語にフォールバックし、まれなデコードエラーも英語で出る場合があります。ファイル名、パス、ファイル内の元の文字は変更しません。

## 対応範囲と制限

- 画像はシステムの ImageIO でデコードします。JPEG、PNG、GIF、HEIC、TIFF、BMP、WebP、RAW などの実際の対応はシステムバージョンとファイル内容に依存します。
- 巨大画像は 1.5 億ピクセルを超えるだけで拒否しません。メモリを制限するため必要時に縮小プレビューを作り、元の寸法と向きを保持します。100% ズームも元の寸法で計算しますが、未デコードの詳細は復元できません。
- SVG、PDF、PDF 互換 AI、内蔵インタープリターが処理する EPS / PS / 旧 AI のベクトル表示に対応します。複数ページ PDF / AI / PS はページをめくれます。SVG はスクリプトと外部リソースを拒否します。ベクトル内のビットマップは元の解像度に制限され、未埋め込みで利用できないフォントは置換される場合があります。
- PostScript は独立プロセスで SAFER とシステムサンドボックスを有効にします。現在の一時入力 / 出力だけを許可し、ネットワークを禁止します。素早いファイル切り替えでキャンセルでき、サムネイルとメイン画像は完成キャッシュを共有します。1 回の解釈は 90 秒、出力は最大 1 GB、キャッシュ整理目標は 2 GB です。
- Photoshop PSD / PSB は保存時の合成画像を表示し、レイヤー編集は行いません。巨大キャンバスはメモリ予算内でプレビューを作り、元の寸法を保持します。色モード、ビット深度、圧縮の詳細は FORMATS.md を参照してください。
- 内蔵互換デコードで音声 / 動画の範囲を広げますが、DRM、破損ファイル、利用可能なデコーダーのない独自形式は再生できない場合があります。拡張子だけでは内部コーデックの対応を保証せず、すべての形式、機器、システム版を個別検証していません。
- 互換キャッシュの整理目標は 2 GB ですが、使用中のファイルにより一時的に超える場合があります。準備ファイル 1 個は最大 8 GB で、空き容量を少なくとも 512 MB 残します。不足すると準備を止めて通知します。
- TIFF は複数ページに対応しますが、未対応の複合画像形式は最初の画像だけを表示します。表示上の回転は原本へ保存しません。編集、削除、ライブラリデータベース、共有、クラウド同期、外部字幕管理はありません。
- ユーザーが開いたローカルメディアとそのフォルダだけを読み取ります。互換再生はローカルキャッシュへ書き込みますが、メディアをアップロードせず、原本を変更しません。

形式の例、キャッシュとプレビューの境界は [FORMATS.md](FORMATS.md) を参照してください。

## ソースからのビルド

Xcode または Swift コンパイラーを含む Command Line Tools が必要です。リポジトリとソース配布には Intel / Apple Silicon のユニバーサル版メディアツールを同梱し、通常のビルドで第三者依存関係の別途インストールやダウンロードは不要です。クローンまたは展開後、`build.sh` のあるリポジトリルートでビルドできます。元の開発ワークスペース構造は不要です。

```bash
cd /path/to/LumaView
./build.sh
open ../LumaView.app
```

既定ではユニバーサルアプリを生成し、`./build.sh --host` は現在の Mac のアーキテクチャのみをビルドします。既定の出力先はソースディレクトリの隣の `LumaView.app` で、`LUMAVIEW_APP_PATH` で変更できます。ビルド / テスト作業ディレクトリは既定でリポジトリ内の `.build/`、`LUMAVIEW_WORK_ROOT` で変更できます。生成ファイルは `.gitignore` で除外しています。

テストビルドは `LUMAVIEW_TEST_BUILD=1 ./build.sh --host` を使います。独立した `LumaView Tests` アプリを生成し、ファイルの関連付けを宣言せず、正式版の関連付けを奪いません。UI テストスクリプトは既定でこのモードを使います。ビルド済みアプリは `LUMAVIEW_SKIP_TEST_BUILD=1` と `LUMAVIEW_TEST_APP_PATH` で指定できます。

FFmpeg は LGPL 2.1 以降、静的リンクした dav1d は BSD 2-Clause ライセンスでビルドしています。対応ソースアーカイブ、チェックサム、ライセンスをソース配布に同梱します。メディアツール再ビルドには Xcode Command Line Tools、Python 3、Meson 1.12.1、Ninja 1.13.2 が必要です。Python 仮想環境に導入後 `./tools/build-media-tools.sh` を実行できます。手順と設定は [ThirdParty/README.md](ThirdParty/README.md) にあります。PostScript は独立した Ghostscript 10.08.0（AGPL-3.0-or-later）を使用し、ライセンス、完全な対応ソース、ビルドスクリプトを同梱します。通常のアプリビルドは同梱の 2 アーキテクチャ部品を使います。再ビルドは [Ghostscript の説明](ThirdParty/README-Ghostscript.md) を参照してください。

## ソースと検証

- `Sources/`：AppKit UI、メディアキャンバス、画像 / ベクトルの読み込み、音声 / 動画のライフサイクル、互換準備、デフォルトアプリ設定。
- `Resources/Localizations/`：翻訳文と必須翻訳キー一覧。
- `Resources/MediaFormats.json`：形式カタログ。`Resources/MediaTools/`：同梱 FFmpeg / ffprobe。
- `ThirdParty/sources/`、`Resources/ThirdPartyNotices/`：メディアツールの対応ソースとライセンス。
- `build.sh`：ユニバーサルアプリのコンパイル、パッケージ化、ローカル署名。`tools/build-media-tools.sh`：メディアツール再ビルド。

音声デコード単体テストは MP3 / FLAC / Opus サンプル生成に対応エンコーダー付き開発版 FFmpeg が必要で、`LUMAVIEW_TEST_FFMPEG` でパスを指定できます。アプリ実行と音声 UI テストは同梱部品だけを使用します。

UI 統合チェックにはログイン済み macOS グラフィカルデスクトップが必要です。アプリを起動し、自動生成メディアで操作を確認します。ビルドファイルと保存レポートは既定で `.build/`、一部の実行素材はシステム一時ディレクトリを使います。テストは既定で個人写真を読みません。右クリックコピーは独立した名前付きクリップボードを使い、現在のコピー内容を上書きしません。「このアプリケーションで開く」/ Finder / デフォルトアプリのテストは模擬インターフェースを使い、関連付けを変更しません。配布版の検証記録は [TEST-RESULTS.txt](TEST-RESULTS.md) にあります。

`Tests/` の保存レポートは各版の過去の検証記録であり、クローン後の現在の環境が自動的に合格したことを示しません。個人サンプルの名前は匿名化し、原本メディアはリポジトリに含めません。過去レポートの `work/` パスは当時のテスト元を記録したもので、現在のビルドに必要なディレクトリではありません。第三者ツールの対応ソースアーカイブ、チェックサム、ライセンスを保持するため、初回クローンは大きくなります。
