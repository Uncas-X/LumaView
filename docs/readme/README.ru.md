Это краткое руководство по началу работы. Полная документация доступна на [английском](README.en.md) и [китайском](../../README.md) языках.

LumaView — нативное приложение для macOS для просмотра изображений, видео, аудио и многостраничных документов. Быстрый просмотр организован по мотивам Picasa Photo Viewer, но у приложения собственные название и значок; оно не связано с Google. LumaView предназначен для просмотра файлов, а не для редактирования фотографий или ведения фототеки.

## Загрузка и установка

**Версия 1.7.2, сборка 14.** Требуется macOS 13 или новее. Универсальная сборка работает на компьютерах Mac с процессорами Intel и Apple Silicon.

1. Скачайте [LumaView для macOS](https://github.com/Uncas-X/LumaView/releases/latest/download/LumaView-macOS.zip). Остальные версии доступны в разделе [выпусков](https://github.com/Uncas-X/LumaView/releases).
2. Распакуйте архив и перетащите `LumaView.app` в папку «Программы».
3. Запустите приложение. Оно имеет локальную подпись ad hoc и не прошло нотариальную проверку Apple. После проверки источника загрузки может потребоваться разрешить запуск в разделе **«Конфиденциальность и безопасность»** настроек macOS.

## Просмотр и возможности

Перетащите файл или папку в окно либо нажмите **Cmd+O**. При открытии одного файла можно переходить к другим медиафайлам в той же папке. Сканируется только текущий уровень папки, без вложенных каталогов.

- Лента миниатюр помогает выбирать файлы. Доступны масштабирование, перемещение изображения, поворот и полноэкранный режим, плавные переходы и полупрозрачный фон с эффектом матового стекла.
- Прозрачные области PNG, GIF, PSD и PSB остаются прозрачными; тень следует контурам содержимого. Страницы документов отображаются на белой бумаге. Для PSD и PSB используется сохранённое совмещённое изображение для совместимости, а не отдельные слои.
- Видео и аудио сначала воспроизводятся средствами системы. Включённый FFmpeg расширяет поддержку, но иногда до начала воспроизведения нужно полностью подготовить файл на локальном диске. Для аудио показывается встроенная обложка, а при её отсутствии — форма звуковой волны. Воспроизведение, пауза и остановка медиа отделены от управления слайд-шоу.
- Поддерживается переход между страницами PDF, совместимых с PDF файлов AI и многостраничных TIFF. SVG, поддерживаемые EPS/PS и старые AI отображаются векторно. EPS/PS обрабатывает включённый Ghostscript; разрешение встроенных растровых изображений остаётся ограниченным исходником.
- Щелчок правой кнопкой позволяет открыть файл другим приложением, показать его в Finder и скопировать изображение, текущий кадр видео, страницу PDF или поддерживаемое встроенное изображение PDF.

В настройках можно выбрать расширения, для которых LumaView станет приложением по умолчанию, и язык интерфейса. Доступно 16 языков; по умолчанию используется язык системы.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| Cmd+O | Открыть файл или папку |
| ← / → | Предыдущий/следующий файл или страница в зависимости от фокуса |
| ↑ / ↓ | Переключить фокус между страницами и файлами многостраничного документа |
| Колесо мыши / жест сведения пальцев / + / − | Изменить масштаб |
| 0 / 1 | Вписать в окно / переключить 100% и вписывание |
| Cmd+R | Повернуть |
| F | Переключить полноэкранный режим |
| P / S | Воспроизвести или приостановить медиа / остановить |
| Cmd+4 | Управлять слайд-шоу |
| Cmd+C | Скопировать изображение, кадр или страницу |

**Пробел меняет фон, а не запускает и не приостанавливает воспроизведение.**

## Сборка

Установите Xcode или инструменты командной строки Swift. Репозиторий содержит необходимые инструменты для обработки медиа, а также соответствующие архивы исходного кода и лицензии. Выполняйте команды из корня репозитория, не из каталога документации:

```bash
./build.sh
open ../LumaView.app
```

Команда `./build.sh --host` собирает приложение только для архитектуры текущего Mac. Создаваемые файлы по умолчанию помещаются в `.build/`. Переменная `LUMAVIEW_WORK_ROOT` меняет этот каталог, а `LUMAVIEW_APP_PATH` — путь выходного приложения.

## Ограничения и конфиденциальность

LumaView читает локальные файлы, не загружает их в облако и не меняет оригиналы. Редактор, редактирование слоёв, база фототеки и облачная синхронизация не предусмотрены. Для крупных изображений может использоваться уменьшенный предпросмотр: увеличение не возвращает исключённые из него детали. Поддержка всех кодеков не гарантируется; защищённые DRM, повреждённые и неподдерживаемые файлы могут не открыться. Преобразование использует локальный дисковый кеш и может занять время.
