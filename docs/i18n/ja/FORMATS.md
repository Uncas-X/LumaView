LumaView 1.7.2 の形式カタログには、画像、ベクトル / 文書、動画、音声の 72 グループがあります。ファイルの検出とデフォルトのアプリ選択に使うカタログであり、全項目を実機検証した互換性一覧ではありません。同じ拡張子でも内部コーデックが異なる場合があります。実際に開けるかは内容、システム能力、内蔵デコーダーで決まります。

## 画像

| 分類 | 形式の例 |
| --- | --- |
| 一般的な画像 | JPEG、PNG / APNG、GIF、TIFF、BMP、HEIC / HEIF、WebP |
| その他の画像 | AVIF、JPEG XL、JPEG 2000、ICO / CUR / ICNS、PSD / PSB、TGA、HDR / OpenEXR、Netpbm |
| カメラ RAW | DNG、Canon CR2 / CR3 / CRW、Nikon NEF / NRW、Sony ARW / SR2 / SRF、ORF、RAF、RW2、PEF、SRW |

画像は macOS ImageIO でデコードします。表はカタログ上の候補であり、特に RAW、新しい画像コーデック、専門形式の対応はシステム版で変わります。独自の RAW デコーダーは同梱しません。GIF はアニメーション、TIFF は複数ページに対応します。ページ操作未実装の他の複合画像形式は先頭画像のみを表示します。

PNG / APNG、GIF、PSD / PSB などのラスター画像の透明部分は、統一して現在の閲覧背景を透過し、市松模様を付けません。影は実際のピクセル透明度で形成し、独立したソフトマスクやアニメーションの各フレームにも対応します。空白キャンバスの縁に長方形の影や枠を付けません。閲覧だけの効果であり、コピーする画像は元の透明度を保持し、表示用の影を含みません。PDF、SVG などのベクトル文書は下記の白い紙面の規則を使います。

**Photoshop PSD / PSB：**ファイル内の合成画像を読み取り、メイン画像、サムネイル、現在表示中の画像のコピーに対応します。Photoshop レイヤーの再構築や編集はしません。互換合成画像を保存していないと明示されたファイルには、Photoshop の「互換性を優先」を有効にして再保存するよう案内します。PSD / PSB はファイル版 1 / 2 に対応し、[Adobe 形式仕様](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)に従い、各辺の上限はそれぞれ 30,000 / 300,000 ピクセルです。

112 の基本符号化組み合わせをデコード検証しました。PSD と PSB の両方で、単一 / 追加チャンネル付きグレースケール、3 / 追加チャンネル付き RGB の 8 / 16 / 32 ビット、CMYK の 8 / 16 ビットを対象とし、各組み合わせで無圧縮、PackBits RLE、ZIP、ZIP prediction を確認しています。さらに実際のレイヤーレコードを含む 128 のグレースケール / RGB サンプルで、8 / 16 / 32 ビットの通常のユーザー alpha と合成透明度の区別を検証しました。正負のレイヤー数、グローバル Lr16/Lr32 レコード、合成透明マーカー、無圧縮 / ZIP を含みます。300,000 × 128 ピクセルの PSB の制限付きプレビュー、メイン画像、サムネイルも確認しました。以上のマトリクスは形式仕様に従って生成したサンプルです。1.7.1 ではさらに約 108–123 MiB の実際のレイヤー、合成透明度、ICC を持つ 3 つの PSB でメイン画像とサムネイルを検証しましたが、あらゆる Photoshop 出力を検証したことにはなりません。

フィルムストリップは Photoshop が保存した有効な RGB JPEG サムネイル（リソース 1036）を優先し、符号化、寸法、縦横比、長さを検証します。欠落、破損、未対応なら合成画像にフォールバックします。埋め込みプレビューは通常小さく、フィルムストリップだけに使います。メイン画面は常に互換合成画像を読みます。RLE は最大 64 KiB のブロックで読み、圧縮マーカーごとのファイル読み取りを避けます。ブロックをまたぐデータや長い no-op 列もキャンセル可能です。

ZIP、高ビット深度 RLE、大画像、追加チャンネル付きファイルは内蔵の行単位フォールバックで読み、その後 ImageIO で色を解釈します。明確な合成透明フラグがあれば対応する透明度を読み、RGB / グレースケールでは合成プレビューの白いマットを除いて独立マスクを付けます。宣言がなければ基本色のみを表示し、保存された選択範囲を透明度と誤認しません。複数 alpha、スポットカラーチャンネル、CMYK 透明度、複雑なマスクの組み合わせは完全検証しておらず、Photoshop のレイヤー合成との一致は保証しません。フォールバックは最初の 4 MiB 以下の埋め込み ICC を保持してシステムへ渡します。有効な ICC を含む小サイズ合成データをシステムが拒否した場合は、ピクセルを別にデコードし、検証済みでモデルと成分が一致する元の ICC を再付与します。プロファイルを単に捨てません。より大きいプロファイルはスキップし、システム既定の色解釈になる場合があります。32 ビットは表示用プレビューで、Photoshop の完全な HDR トーン制御はありません。Lab、インデックスカラー、ダブルトーン、その他の特殊モードは上記検証マトリクスに含まず、開けるかはファイル構造とシステムデコード能力次第です。1 ビット PackBits は別途小画像のネイティブデコードを確認しています。

大画像は 1.5 億ピクセルを超えただけで拒否しません。ローダーはメモリ予算に基づいてプレビューを作り、最長辺は最大 8192 ピクセル、総量は約 3200 万ピクセル以下で、実際にはさらに小さい場合があります。情報パネルは元の寸法と向きを保持し、縮小プレビューであることを示します。ズーム倍率は元の寸法で計算し、未デコードの原画像の詳細は拡大しても得られません。破損やデコード不能のファイルは引き続きエラーになります。

## ベクトルと文書

| 形式 | 現在の動作 |
| --- | --- |
| SVG | システムのベクトルレンダラーでオフライン描画し、ズームに応じて更新します。認識済みの標準 SVG DTD 宣言は許可しますが DTD を読み込みません。独自 / 内部 DTD、スクリプト、イベント処理、外部リソースを拒否するため、一部の複雑 / 動的 SVG は表示できません。 |
| PDF | 複数ページサムネイル、進捗バー、ページ番号、フォーカス、キーボードでのページ操作に対応します。現在の倍率で描画し、クロップボックスとページの向きを保持します。文書編集はありません。 |
| AI | PDF 互換データがあれば直接表示し、複数ページ / アートボードにも対応します。旧 PostScript AI は内蔵 Ghostscript でベクトル PDF へ変換します。Illustrator 独自データしか含まないファイルは開けるとは限りません。 |
| EPS / PostScript | 内蔵 Ghostscript 10.08.0 が描画内容全体を PDF へ変換し、パス、文字、埋め込み画像を保持してベクトルキャンバスに表示します。複数ページ PS に対応します。解釈に失敗し DOS EPS に有効な埋め込み TIFF があれば、ラスターと明示してフォールバックします。ビットマップには元の解像度の制約が残り、未埋め込みで利用不能なフォントは置換される場合があります。 |

メインキャンバスは PDF / SVG のベクトルソースを保持し、512 ピクセルのタイルで現在の倍率の可視領域を描き、最大 3200% に対応します。ページをめくる際は、画面に合うページ全体の下地を背景で用意し、全体のトランジション後に元のベクトル層が現在倍率の詳細を補います。未描画領域がタイルごとに出現するのを防ぎます。下地の最長辺は最大 4096 ピクセルですが、ベクトル層の拡大鮮明度は制限しません。紙面は市松模様のない白で、写真などの埋め込みビットマップは元の解像度に制限されます。TIFF の各ページには大画像と同じ制限付きラスタープレビューを使います。暗号化され未解除の PDF にパスワード入力はなく、直接閲覧できません。描画は原本を書き換えません。

PDF / PDF 互換 AI は、右クリックした埋め込みビットマップまたはページ全体のコピーに対応します。一般的な XObject、インライン画像、ネストされた Form、クリップ、ページ方向を扱えます。複雑なマスクや色空間は該当する可視領域の描画結果を使います。Pattern 内のビットマップなど特殊構造や走査予算を超えるページでは、埋め込み画像を個別にコピーできない場合があります。出力は PNG/TIFF ビットマップで、最長辺は最大 8192 ピクセル、総量は約 3200 万ピクセルです。原本は変更しません。

## 動画と音声

| 分類 | 形式カタログの例 |
| --- | --- |
| 一般的な動画コンテナ | MP4 / M4V、MOV、MKV、WebM、AVI、FLV、WMV / ASF、MPEG、TS / M2TS、3GP |
| その他の動画とビットストリーム | OGV、RM / RMVB、VOB、MOD / TOD、Motion JPEG、MXF、DV、NUT、NSV、AMV、Bink / Smacker、H.264、HEVC、VVC、IVF、Y4M ビットストリーム |
| 一般的な音声 | MP3、AAC、M4A、WAV、AIFF、CAF、FLAC、Ogg / Vorbis、Opus、WMA |
| その他の音声 | Speex、APE、WavPack、TTA、TAK、Shorten、AC-3 / E-AC-3 / TrueHD、DTS、AMR、AU / SND、RealAudio、DSD、MKA、Musepack、GSM / QCP、IFF Audio |

まずシステムの AVFoundation で再生します。直接再生できなければ、同梱 FFmpeg 9.0.2 / ffprobe を使います。AV1 デコード用の dav1d 1.5.3 を静的リンクしています。条件を満たす動画は動画コーデックを維持してコンテナ変更を試し、それでも無理ならシステムで再生できる符号化へ変換します。音声も互換準備で再生できます。

互換準備はネットワークを無効にしたローカル処理で、追加インストールは不要です。全ファイルの処理を先に完了するため、即時再生は保証しません。進捗を表示し、ファイル切り替えやウィンドウを閉じるとキャンセルします。変換により画質、音質、色が変わる場合がありますが、原本は不変です。高解像度、高フレームレート、複雑な符号化、長いファイルの処理速度は機器に依存します。

キャッシュは 2 GB を目標に自動整理しますが、使用中のファイルは保持するため厳密な総量上限ではありません。準備ファイル 1 個は最大 8 GB、ディスクの空きは少なくとも 512 MB 必要です。限界を超えると停止してエラーを表示します。再度開くと有効なキャッシュを再利用できます。

DRM 保護、破損、未同梱の外部デコーダー、独自符号化、一部の特殊コンテナは再生できない場合があります。珍しい形式もカタログに含みますが、すべての利用可能性は約束せず、各コーデック組み合わせを個別検証していません。外部字幕管理、ディスクメニュー、ストリーミング再生は現在提供しません。

## 音声のカバーと波形

メイン領域は原本の埋め込みカバーを優先し、まずネイティブメタデータを読み、必要時に内蔵ツールで attached picture を抽出します。カバーのデコードは最長辺 2048 ピクセルに制限し、失敗時は波形へ戻ります。カバーのないファイルについてネットワークから取得したり、同じディレクトリの cover.jpg を読んだりしません。

カバーがなければ実際にデコードしたサンプルから全音声のピーク包絡を生成します。最大 4096 サンプル区間を保持し、各 PCM バッファも制限するため、長い音声全体をメモリへ読みません。互換音声は準備済みのローカル再生ファイルから波形を作ります。波形は全体概観であり、リアルタイムスペクトルではありません。生成中も再生を続行できます。切り替えや閉じる操作で解析をキャンセルし、遅い結果が現在のファイルを上書きしません。フィルムストリップの再生時間は独立して非同期取得するため、各ファイルを先に選ぶ必要はありません。音声と動画のバッジはともに `▶ 再生時間` です。

## デフォルトアプリの設定

**LumaView → デフォルトのアプリケーション…** または `⌘,` で形式グループを選択して設定します。開いたとき、再アクティブ化時、設定完了時に実際のシステム関連付けを読みます。関連付けは再起動後も保存されます。チェックは全タイプが現在のアプリに一致すること、横線は一部のみ、または別の LumaView コピーを指すことを示します。上の「すべての形式を選択」は検索に関係なく全分類を対象にし、分類内の「すべて選択」はその分類だけを対象にできます。未適用の選択は今回の下書きであり、クリアしても書き込み済みの関連付けは解除しません。システムが同じタイプ識別子を持つ複数拡張子を 1 種として扱い、一緒に変更する場合があります。

結果をシステムから読み戻し、失敗した形式を報告します。キャンセルは未実行の変更だけを止め、完了した設定を自動で戻しません。ある形式を戻すには、Finder の「情報を見る → このアプリケーションで開く → すべてを変更」で元のアプリを選択できます。
