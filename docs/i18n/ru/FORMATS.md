Каталог форматов LumaView 1.7.2 содержит 72 группы изображений, векторов / документов, видео и аудио. Он служит для обнаружения файлов и выбора приложения по умолчанию, а не является перечнем поштучно проверенной совместимости. Одинаковое расширение может скрывать разное кодирование; возможность открытия зависит от содержимого, системных возможностей и встроенных декодеров.

## Изображения

| Категория | Примеры форматов |
| --- | --- |
| Распространённые изображения | JPEG, PNG / APNG, GIF, TIFF, BMP, HEIC / HEIF, WebP |
| Другие изображения | AVIF, JPEG XL, JPEG 2000, ICO / CUR / ICNS, PSD / PSB, TGA, HDR / OpenEXR, Netpbm |
| RAW камер | DNG, Canon CR2 / CR3 / CRW, Nikon NEF / NRW, Sony ARW / SR2 / SRF, а также ORF, RAF, RW2, PEF, SRW |

Изображения декодируются macOS ImageIO. Таблица перечисляет варианты из каталога; поддержка RAW, новых кодировок и профессиональных форматов особенно зависит от версии системы. Отдельный RAW-декодер не поставляется. GIF поддерживает анимацию; TIFF — страницы; остальные составные форматы без реализованной пагинации показывают первый кадр.

Прозрачные области растров PNG / APNG, GIF, PSD / PSB и других форматов единообразно показывают текущий фон без шахматной сетки. Тень формируется по реальной прозрачности пикселей, включая отдельные мягкие маски и каждый кадр анимации; прямоугольная тень или рамка по пустому краю холста не добавляется. Эффект применяется только при просмотре: копия сохраняет исходную прозрачность без тени просмотра. Векторные документы PDF, SVG и другие следуют описанному ниже правилу белой бумаги.

**Photoshop PSD / PSB:** читается встроенный композит для основного вида, миниатюр и копирования текущего изображения; слои Photoshop не пересоздаются и не редактируются. Если файл явно сохранён без совместимого композита, предлагается включить в Photoshop «Максимальная совместимость» и сохранить повторно. PSD / PSB соответствуют версиям файлов 1 / 2; по [спецификации Adobe](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/) максимальная сторона составляет соответственно 30,000 / 300,000 пикселей.

Декодирование проверено на 112 базовых комбинациях: PSD и PSB с одноканальным / дополнительными каналами серым, трёхканальным / дополнительными каналами RGB при 8 / 16 / 32 битах, и CMYK при 8 / 16 битах; для каждой комбинации проверены отсутствие сжатия, PackBits RLE, ZIP и ZIP prediction. Ещё 128 серых/RGB-образцов с реальными записями слоёв проверяют различие обычной пользовательской alpha и прозрачности композита при 8 / 16 / 32 битах, положительное/отрицательное число слоёв, глобальные записи Lr16/Lr32, маркеры прозрачности композита и несжатое/ZIP-кодирование. Также проверен ограниченный предпросмотр PSB 300,000 × 128 пикселей, основной вид и миниатюры. Образцы матрицы созданы по спецификации. В 1.7.1 дополнительно проверены основной вид и миниатюры трёх реальных PSB примерно 108–123 MiB со слоями, прозрачным композитом и ICC; это не означает проверку любого экспорта Photoshop.

Лента прежде всего читает корректную RGB JPEG-миниатюру Photoshop (ресурс 1036), проверяя кодировку, размеры, пропорции и длину. При отсутствии, повреждении или неподдерживаемом превью используется композит. Встроенное превью обычно маленькое и используется только в ленте; основной вид всегда читает совместимый композит. RLE читается блоками до 64 KiB, без отдельного обращения к файлу для каждого маркера сжатия; отмена остаётся доступной для данных на границах блоков и длинных последовательностей no-op.

ZIP, RLE высокой разрядности, большие файлы и дополнительные каналы используют встроенное резервное построчное чтение, затем ImageIO интерпретирует цвет. При явном маркере прозрачности композита считывается соответствующая прозрачность; для RGB/серого удаляется белая подложка композитного превью и добавляется отдельная маска. Без такого маркера отображаются только базовые цвета, а сохранённые выделения не принимаются за прозрачность. Несколько alpha, плашечные каналы, прозрачность CMYK и сложные маски полностью не проверены; соответствие композиции слоёв Photoshop не гарантируется. Резервное чтение сохраняет первый встроенный ICC до 4 MiB для системной обработки. Если система отвергает маленький композит с корректным ICC, пиксели декодируются отдельно, затем снова прикрепляется проверенный исходный ICC с совпадающими моделью и компонентами; профиль не отбрасывается. Большие профили пропускаются, и цвет может интерпретироваться системными настройками. 32-битные данные предназначены для предпросмотра, без полного HDR-тонального управления Photoshop. Lab, индексированный цвет, дуплекс и другие специальные режимы не входят в матрицу; их открытие зависит от структуры файла и системы. Для 1-битного PackBits есть отдельная проверка нативного декодирования небольшого изображения.

Большие изображения не отклоняются лишь потому, что превышают 150 миллионов пикселей. Загрузчик создаёт предпросмотр в рамках бюджета памяти: до 8192 пикселей по длинной стороне и примерно 32 миллионов пикселей суммарно, фактический размер может быть меньше. Панель информации сохраняет исходные размеры и ориентацию, отмечая уменьшенный предпросмотр. Масштаб рассчитан по исходным размерам; увеличение предпросмотра не даёт недекодированных деталей оригинала. Повреждённые или недекодируемые файлы по-прежнему вызывают ошибку.

## Векторы и документы

| Формат | Текущее поведение |
| --- | --- |
| SVG | Офлайн-отрисовка системным векторным рендерером с обновлением масштаба; распознанные стандартные объявления SVG DTD разрешены без загрузки DTD; пользовательские/внутренние DTD, скрипты, обработчики событий и внешние ресурсы запрещены. Некоторые сложные или динамические SVG могут не отображаться. |
| PDF | Миниатюры страниц, ползунок, номера, фокус и клавиатурная навигация; отрисовка при текущем масштабе с сохранением рамки обрезки и ориентации; без редактирования документа. |
| AI | PDF-совместимые данные отображаются напрямую, включая несколько страниц / монтажных областей; старые PostScript AI преобразуются встроенным Ghostscript в векторный PDF; открытие файлов только с проприетарными данными Illustrator не гарантируется. |
| EPS / PostScript | Встроенный Ghostscript 10.08.0 преобразует полное рисуемое содержимое в PDF с сохранением путей, текста и встроенных изображений, затем показывает векторным холстом; поддерживаются многостраничные PS. Если интерпретация не удалась, а DOS EPS содержит корректный TIFF, возможен помеченный растровый предпросмотр. Растр ограничен исходным разрешением; отсутствующие невстроенные шрифты могут заменяться. |

Основной холст сохраняет векторные источники PDF / SVG и рисует видимую область плитками по 512 пикселей при текущем масштабе, до 3200%. При листании сначала в фоне готовится целая подложка страницы по размеру экрана; после перехода всей страницы исходный векторный слой дополняет детали текущего масштаба, избегая появления пустых частей по одной. Подложка ограничена 4096 пикселями по длинной стороне и не снижает чёткость увеличенного вектора. Бумага белая, без шахматной сетки; детализация встроенных фотографий ограничена источником. Каждая страница TIFF использует ограниченный растровый предпросмотр, как большие картинки. Для зашифрованного неразблокированного PDF ввода пароля нет, напрямую просмотреть его нельзя. Рендеринг не изменяет оригиналы.

PDF / AI с PDF-совместимостью позволяет правой кнопкой копировать выбранное встроенное растровое изображение или всю текущую страницу. Поддерживаются распространённые XObject, inline-изображения, вложенные Form, обрезка и ориентация. Для сложных масок и цветовых пространств используется отрисованный видимый участок. Растр внутри Pattern и других специальных структур или страницы, превышающие бюджет сканирования, могут не позволять отдельное копирование изображения. Результат — PNG/TIFF до 8192 пикселей по длинной стороне и примерно 32 миллионов пикселей; оригинал не меняется.

## Видео и аудио

| Категория | Примеры из каталога |
| --- | --- |
| Распространённые видеоконтейнеры | MP4 / M4V, MOV, MKV, WebM, AVI, FLV, WMV / ASF, MPEG, TS / M2TS, 3GP |
| Другие видео и потоки | OGV, RM / RMVB, VOB, MOD / TOD, Motion JPEG, MXF, DV, NUT, NSV, AMV, Bink / Smacker, а также потоки H.264, HEVC, VVC, IVF, Y4M |
| Распространённое аудио | MP3, AAC, M4A, WAV, AIFF, CAF, FLAC, Ogg / Vorbis, Opus, WMA |
| Другое аудио | Speex, APE, WavPack, TTA, TAK, Shorten, AC-3 / E-AC-3 / TrueHD, DTS, AMR, AU / SND, RealAudio, DSD, MKA, Musepack, GSM / QCP, IFF Audio |

Сначала выполняется попытка воспроизведения системным AVFoundation. Если напрямую не удаётся, используются встроенные FFmpeg 9.0.2 / ffprobe со статически связанным dav1d 1.5.3 для AV1. Для подходящего видео сначала меняется контейнер с сохранением кодирования; при неудаче кодирование преобразуется в системно поддерживаемое. Аудио также может проходить подготовку совместимости.

Подготовка выполняется локально, сеть отключена, дополнительных установок не нужно. Обрабатывается весь файл, поэтому мгновенное начало не гарантируется. Интерфейс показывает прогресс; переключение файла или закрытие окна отменяет операцию. Перекодирование может менять качество изображения, звука и цветопередачу; оригинал остаётся неизменным. Скорость для высокого разрешения, частоты кадров, сложных кодеков и длинных файлов зависит от устройства.

Кеш очищается автоматически с целью 2 GB; используемые файлы сохраняются, поэтому это не строгий общий предел. Один подготовленный файл ограничен 8 GB, а свободный остаток диска должен быть не менее 512 MB; превышение останавливает операцию с ошибкой. Повторное открытие может использовать действующий кеш.

Защищённые DRM и повреждённые файлы, отсутствующие внешние декодеры, проприетарные кодировки и некоторые специальные контейнеры могут не воспроизводиться. Каталог содержит редкие форматы, но не обещает доступность всех и не проверяет каждую комбинацию кодирования. Нет управления внешними субтитрами, меню дисков и потокового воспроизведения.

## Обложки и аудиоволны

Основной вид прежде всего использует встроенную обложку оригинала: сначала читаются нативные метаданные, при необходимости встроенный инструмент извлекает attached picture. Обложка декодируется до 2048 пикселей по длинной стороне; при ошибке используется волна. Если обложки нет, она не скачивается из сети и не читается из соседнего cover.jpg.

Без обложки из фактически декодированных отсчётов строится пиковая огибающая всего аудио, максимум 4096 интервалов. Каждый PCM-буфер ограничен, поэтому даже длинное аудио не загружается целиком в память. Для совместимого аудио волна строится из подготовленного локального файла. Это обзор всего звука, а не спектр в реальном времени; генерация не мешает воспроизведению. Переключение файла или закрытие отменяет анализ, поздний результат не заменяет текущий файл. Длительность в ленте читается независимо и асинхронно, без выбора каждого файла; значки аудио и видео имеют вид `▶ Длительность`.

## Настройка приложения по умолчанию

Через **LumaView → Приложение по умолчанию…** или `⌘,` отметьте группы форматов и примените. При каждом открытии, повторной активации и завершении читаются реальные системные ассоциации, сохраняемые после перезапуска. Галочка означает совпадение всех типов с текущим приложением, черта — частичное совпадение или другую копию LumaView. Верхняя команда «Выбрать все форматы» охватывает все категории независимо от поиска; «Выбрать всё» внутри группы — только эту категорию. Неприменённые отметки — текущий черновик; очистка не отменяет успешно записанные ассоциации. Система может считать расширения с одним идентификатором типа одним типом, поэтому некоторые расширения меняются вместе.

Интерфейс повторно читает системный результат и сообщает о неудачных форматах. Отмена прекращает только ещё не выполненные изменения; завершённые автоматически не откатываются. Чтобы восстановить прежнюю программу для формата, выберите её в Finder: «Свойства → Открывать в программе → Настроить всё».
