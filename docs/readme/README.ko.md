이 문서는 빠른 시작 안내서입니다. 자세한 내용은 [전체 영문 설명서](README.en.md) 또는 [전체 중국어 설명서](../../README.md)를 참고하세요. 현재 버전은 **1.7.2(빌드 14)**입니다.

LumaView는 이미지, 동영상, 오디오, 여러 페이지 문서를 볼 수 있는 macOS 네이티브 뷰어입니다. Picasa Photo Viewer의 빠른 탐색 방식에서 영감을 받았으며, 자체 이름과 독창적인 아이콘을 사용합니다. Google과 제휴 관계가 없으며, 사진 편집이나 보관함 관리보다 파일 감상과 탐색에 집중합니다.

## 다운로드 및 설치

[LumaView for macOS](https://github.com/Uncas-X/LumaView/releases/latest/download/LumaView-macOS.zip)를 다운로드하거나 [전체 릴리스](https://github.com/Uncas-X/LumaView/releases)를 확인하세요. **macOS 13 이상**이 필요하며 Intel과 Apple Silicon을 모두 지원하는 유니버설 앱입니다.

압축을 풀고 `LumaView.app`을 응용 프로그램 폴더로 옮기세요. 현재 앱은 로컬 ad-hoc 서명을 사용하며 Apple 공증을 받지 않았습니다. macOS가 실행을 차단하면 다운로드 출처를 확인한 후 시스템 안내에 따라 개인정보 보호 및 보안에서 실행을 허용할 수 있습니다.

## 기본 사용법

파일이나 폴더를 앱으로 끌어다 놓거나 `Cmd+O`로 여세요. 파일 하나를 열면 같은 폴더에 있는 앞뒤 미디어 파일도 탐색할 수 있습니다. 폴더 검색은 현재 폴더에만 적용되며 하위 폴더는 포함하지 않습니다.

- 하단 썸네일 목록으로 파일을 전환하고 확대·축소, 화면 이동, 회전, 전체 화면 기능을 사용할 수 있습니다. 부드러운 전환 효과와 반투명 유리 효과 배경을 제공합니다.
- PNG, GIF, PSD, PSB의 래스터 투명 영역은 그대로 유지하고 내용의 형태에 맞춰 그림자를 표시합니다. 문서 페이지는 흰 종이 배경으로 표시합니다. PSD/PSB는 저장된 호환 합성 이미지를 사용하며 개별 레이어를 편집하지 않습니다.
- 동영상과 오디오는 시스템 재생 기능을 먼저 사용하고 필요할 때 내장 FFmpeg로 호환 처리를 진행합니다. 오디오에 내장 커버 이미지가 있으면 표시하고, 없으면 파형을 표시합니다.
- PDF, PDF 호환 AI, 다중 페이지 TIFF에서 페이지를 탐색할 수 있습니다. SVG, 지원되는 EPS/PS 및 구형 AI는 벡터로 렌더링합니다. EPS/PS에는 내장 Ghostscript를 사용하지만, 문서에 포함된 비트맵은 원본 해상도의 제한을 받습니다.
- 주 화면을 오른쪽 클릭하면 다른 앱으로 열기, Finder에서 보기, 이미지 복사, 동영상의 현재 프레임 복사, PDF 페이지 또는 지원되는 PDF 내부 이미지 복사를 선택할 수 있습니다.
- 오디오·동영상 재생/일시 정지 및 정지 버튼은 슬라이드쇼 제어와 분리되어 있습니다. 형식별 기본 앱을 설정할 수 있으며 인터페이스는 16개 언어를 지원합니다. 기본 언어 설정은 시스템을 따릅니다.

## 주요 단축키

| 키 | 기능 |
|---|---|
| `Cmd+O` | 파일 또는 폴더 열기 |
| `←` / `→` | 현재 초점에 따라 이전/다음 파일 또는 페이지로 이동 |
| `↑` / `↓` | 다중 페이지 문서에서 페이지 목록/파일 목록으로 초점 이동 |
| 휠, 핀치, `+` / `-` | 확대 및 축소 |
| `0`; `1` | 창에 맞추기; 100%/창에 맞추기 전환 |
| `Cmd+R`; `F` | 회전; 전체 화면 |
| `P`; `S` | 미디어 재생/일시 정지; 정지 |
| `Cmd+4` | 슬라이드쇼 제어 |
| `Cmd+C` | 이미지, 현재 프레임 또는 페이지 복사 |

**스페이스 키는 배경을 전환**하며 재생/일시 정지를 제어하지 않습니다. 다중 페이지 문서에서 초점이 있는 목록의 현재 항목은 주황색 테두리, 다른 목록의 현재 항목은 회색 테두리로 표시합니다.

## 소스에서 빌드

Xcode 또는 Swift 명령줄 도구를 설치한 후 저장소 루트에서 실행하세요.

```bash
./build.sh
open ../LumaView.app
```

`./build.sh --host`는 현재 Mac 아키텍처만 빌드합니다. 생성되는 중간 파일은 기본적으로 `.build/`에 저장합니다. `LUMAVIEW_WORK_ROOT`로 작업 디렉터리를, `LUMAVIEW_APP_PATH`로 앱 출력 경로를 바꿀 수 있습니다. 경로 기준은 이 문서의 디렉터리가 아니라 저장소 루트입니다. 필요한 미디어 도구와 해당 소스·라이선스 아카이브가 저장소에 포함되어 있습니다.

## 제한 및 개인정보 보호

로컬 파일만 읽으며 클라우드로 업로드하거나 원본을 수정하지 않습니다. 편집기, 레이어 편집, 사진 보관함 데이터베이스, 클라우드 동기화는 제공하지 않습니다. 큰 이미지는 메모리 사용량을 제한한 축소 미리보기로 표시할 수 있으며, 확대해도 미리보기에서 생략된 세부 사항은 복원되지 않습니다.

일부 미디어는 재생 전에 파일 전체를 로컬에서 변환해야 하므로 시간이 걸리고 디스크 캐시를 사용합니다. 시스템 디코더와 내장 호환 도구가 모든 코덱을 지원하는 것은 아닙니다. DRM이 적용되었거나 손상되었거나 지원되지 않는 파일은 열리지 않을 수 있습니다.
